# M6 P0 요구사항 점검 (2026-11-15)

PRD의 P0 요구사항(FR-\*, NFR-\*, MVP 완료 정의)이 `main`에서 어디까지 구현됐는지 점검한 기록입니다.
요구사항마다 상태와 근거(코드·테스트)를 적고, v0.3 베타 전에 고칠 것과 v1.0(M7)으로 넘길 것을 나눕니다.

- 상태: 완료
- 점검: AI 에이전트 (로드맵 M6 작업 4 "나머지 P0 요구사항 점검과 구현", 사용자 위임)
- 점검 기준: `origin/main` `0521322` (2026-11-15, #104까지). PR을 열기 직전 `a2ae975`(#99·#105 병합)로 다시 맞췄습니다
- 관련 문서: [PRD](/docs/product/prd.md), [구현 로드맵](/docs/roadmap.md), [결정 기록](/docs/decisions.md) D-001~D-051, [변경 이력](/CHANGELOG.md)

## 점검 방법

1. PRD의 P0 요구사항 표(CUR, EX, CODE, LRN, GOAL, AI, DASH, SET, UI), 비기능 요구사항(NFR-01~14), 주요 흐름 1~5, 각 영역의 완료 기준, MVP 완료 정의를 목록으로 만들었습니다.
1. 요구사항마다 설계 문서의 구현 메모와 결정 기록에서 해석을 확인한 뒤, **코드와 테스트에서 직접** 확인했습니다. 문서에 "구현함"이라고 적혀 있어도 코드에서 동작을 찾지 못하면 구현으로 보지 않았습니다. 영역을 셋으로 나눠 독립 검색 에이전트가 1차로 찾고, 빈틈으로 보고된 항목은 직접 다시 확인했습니다. 1차 보고 중 두 건은 다시 확인해 판정을 바꿨습니다(FR-EX-07의 비결정성 거부, FR-AI-03의 "왜 틀렸나요?" 빠른 질문).
1. 상태는 네 가지입니다.

| 상태 | 뜻 |
|---|---|
| 구현됨 | 요구사항과 완료 기준을 만족하고 테스트가 있음 |
| 부분 | 핵심은 동작하지만 요구사항 문장 일부가 빠짐. "빈틈" 열에 무엇이 빠졌는지 적음 |
| 미구현 | 동작하는 코드가 없음 |
| 진행 중 | 열린 PR이나 병렬 작업이 다루는 중 |

1. 이번 점검과 함께 보완한 항목은 "이번에 보완"으로 표시했습니다([D-051](/docs/decisions.md)).
