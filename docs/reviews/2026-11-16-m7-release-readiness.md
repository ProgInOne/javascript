# M7 릴리스 준비 점검 (2026-11-16)

v1.0 MVP의 완료 조건을 M7 작업이 끝난 `main`에서 하나씩 확인한 결과입니다. 이 점검으로 `v1.0.0-rc.1` 출시 후보를 내고, 사람이 해야 하는 점검이 끝나면 `v1.0.0`을 냅니다([D-075](/docs/decisions.md)).

- 대상: `main` 커밋 `6ed50fb`(#122 병합 직후, M7 PR #112~#124 반영)
- 결론: **MVP 완료 정의 1~4는 만족합니다.** 5번(실제 사용자 검증)과 로드맵 M7의 수동 접근성·호환성 점검은 학습자 본인의 진행을 기다립니다.

## 릴리스 전 확인 결과

[릴리스 절차](/docs/guides/release.md#릴리스-전-확인)의 항목입니다.

- **CI**: `main`의 `check`·`e2e` 작업이 self-hosted runner에서 통과합니다(D-055). 검사 작업이 E2E와 함께 돌면 15분 제한에 걸려 취소되던 문제는 제한 시간을 30분으로 늘려 고쳤습니다(#125).
- **콘텐츠**: `pnpm content:check:run --frozen` 오류 0개, 경고 0개. 과정 3, 단원 63, 개념 169, 승인된 문제 1,133개, 템플릿 3개(검증된 변형 90개).
- **성능** (`pnpm perf`, Apple M1 Pro, 다른 작업이 함께 도는 부하 상태, load average 약 13~16):

  | 항목 | 목표 | 중앙값 | 최대 |
  |---|---|---|---|
  | 결정론적 채점(NFR-01) | 300ms | 31ms | 37ms |
  | 콘솔 첫 출력, 페이지의 첫 실행(NFR-02) | 500ms | 98ms | 98ms |
  | 콘솔 첫 출력, 이후 실행(NFR-02) | 500ms | 98ms | 99ms |
  | 무한 루프 중 가장 긴 프레임 간격(NFR-03) | 100ms | 17ms | 17ms |
  | 화면 전환, 첫 방문(NFR-01) | 200ms | 30ms | 118ms |
  | 화면 전환, 다시 방문(NFR-01) | 200ms | 14ms | 15ms |
  | 첫 화면, 빈 캐시(NFR-01) | 2초 | 176ms | 193ms |

  CPU 4배 감속 측정은 [성능 점검의 개선 후 측정](/docs/reviews/2026-11-16-m7-performance.md)에 있습니다.
- **시각 기준 이미지**: M7의 모든 화면 변경을 반영한 상태에서 Docker로 다시 만들었습니다(#122).

## 사람이 해야 하는 점검

`v1.0.0` 전에 학습자가 출시 후보로 진행합니다. 결과는 문제 목록으로 정리해 고친 뒤 `v1.0.0`(또는 `rc.2`)에 반영합니다.

1.  **실제 사용 점검**(MVP 완료 정의 5): JS 기초 모듈 1~3을 처음부터 학습하며 막히거나 헷갈린 곳, 문제의 오류, 화면 사용성 문제를 기록합니다.
1.  **키보드·스크린 리더 수동 점검**(로드맵 M7 작업 4): 마우스 없이 레슨 읽기 → 연습 세트(코드 문제 포함) → 튜터 → 설정까지 진행하고, VoiceOver로 주요 화면의 제목·랜드마크·알림이 읽히는지 확인합니다. 코드 유형을 키보드만으로 푸는 E2E가 없어 이 점검이 유일한 확인입니다.
1.  **다른 브라우저 수동 점검**(NFR-10): Safari·Firefox·Edge에서 레슨 예제 실행, 코드 문제 채점, 웹 실습 미리보기가 동작하는지 확인합니다. 자동 점검(#118)은 Firefox·WebKit에서 샌드박스 정책만 봅니다.

## 알려진 제약

- 콘솔 폭주 중 프레임 간격 E2E(`sandbox.spec.ts` S34·S35, 기준 100ms)가 같은 Mac에서 CI E2E가 함께 돌면 가끔 실패합니다. 부하 없는 반복 실행에서는 통과합니다.
- 다크 모드 대시보드 로딩 화면(`dashboard-loading-dark-1280`)의 스켈레톤 블록이 카드 배경과 거의 구분되지 않습니다. 장식 요소라 axe 위반은 아닙니다.
- 학습 화면 첫 방문은 CodeMirror가 대부분인 조각을 받아 CPU 4배 감속에서 약 0.7초 걸립니다. CodeMirror 지연 로드는 후속 후보입니다(D-074).
- 커리큘럼 레일, ⌘K 커맨드 팔레트(P1), 이동 단축키, 한 글자 단축키 끄기 설정은 아직 없습니다(D-067).
- 단계적 풀이 예제는 JS 기초 모듈 2~5의 `core` 개념에만 있습니다. 모듈 6 이후는 후속입니다(D-072).
- self-hosted runner는 임시 조치입니다. 2026-11-30 무렵 GitHub 호스트 runner로 돌아가고, 저장소를 공개하기 전에 runner를 제거합니다(D-055).
