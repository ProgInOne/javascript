<Section kind="objectives">
- 나란히 놓을 요소들의 부모에 `display: flex`를 주어 플렉스 컨테이너를 만들 수 있어요.
- `flex-direction`에 따라 주축과 교차축이 어느 방향인지 말할 수 있어요.
- `justify-content`와 `align-items`로 아이템을 주축·교차축 방향으로 정렬할 수 있어요.
- `gap`으로 아이템 사이의 간격을 정하고, 가장자리 간격과 구분할 수 있어요.
</Section>

<Section kind="prerequisites" />

<Section kind="intro">
"display와 흐름" 단원에서 블록 요소는 너비를 줄여도 항상 위아래로 쌓인다는 것을 봤어요. 그런데 실제 웹 페이지에는 가로로 놓인 것이 아주 많아요.

- 사이트 맨 위의 로고와 메뉴가 한 줄에 놓여 있어요.
- 상품 카드 세 장이 나란히 놓여 있고, 카드 사이 간격이 똑같아요.
- 버튼 안의 아이콘과 글자가 세로 가운데에 맞춰져 있어요.

`inline-block`으로도 나란히 놓을 수는 있지만, 간격을 똑같이 맞추거나 세로 가운데로 정렬하기가 까다로워요. **Flexbox**(플렉스박스)는 "자식들을 한 줄로 놓고, 그 줄 안에서 정렬과 간격을 정하는" 일을 위해 만든 배치 방법이에요. 속성 몇 개만 알면 위의 모습을 모두 만들 수 있어요.
</Section>

<Section kind="principle">
### 컨테이너와 아이템

부모 요소에 `display: flex`를 주면 그 부모는 **플렉스 컨테이너**가 되고, 부모의 **바로 아래 자식**들은 **플렉스 아이템**이 돼요. 아이템들은 블록이든 인라인이든 상관없이 한 줄로 나란히 놓여요.

```css
.list {
  display: flex; /* .list의 바로 아래 자식들이 한 줄로 놓여요 */
}
```

두 가지를 꼭 기억하세요.

- `display: flex`는 나란히 놓을 요소들이 아니라, 그 요소들을 **감싼 부모**에 줘요.
- 아이템이 되는 것은 **바로 아래 자식**뿐이에요. 손자 요소는 자기 부모 안에서 원래대로 배치돼요.

### 주축과 교차축

Flexbox는 방향을 두 개의 축으로 생각해요.

| 축 | 뜻 | `flex-direction: row` (기본값) | `flex-direction: column` |
|---|---|---|---|
| 주축 | 아이템이 늘어서는 방향 | 가로 (왼쪽 → 오른쪽) | 세로 (위 → 아래) |
| 교차축 | 주축과 수직인 방향 | 세로 | 가로 |

```text
row (기본값)                    column
주축 ───────────▶               주축
┌─────┐┌─────┐┌─────┐            │  ┌─────┐
│  1  ││  2  ││  3  │            │  │  1  │
└─────┘└─────┘└─────┘            │  ├─────┤
                                 │  │  2  │
                                 │  ├─────┤
                                 ▼  │  3  │
                                    └─────┘
```

`flex-direction`이 주축을 정하고, 교차축은 자동으로 그와 수직인 방향이 돼요.

### 주축 정렬과 교차축 정렬

정렬 속성은 **축마다 하나씩** 있어요. 속성 이름이 "가로", "세로"가 아니라 "주축", "교차축"을 기준으로 한다는 점이 핵심이에요.

<CompareTable columns={["justify-content", "align-items"]}>
<Row label="정렬하는 축">주축 | 교차축</Row>
<Row label="row일 때 방향">가로 | 세로</Row>
<Row label="column일 때 방향">세로 | 가로</Row>
<Row label="자주 쓰는 값">`flex-start`, `center`, `flex-end`, `space-between` | `stretch`(기본값), `flex-start`, `center`, `flex-end`</Row>
</CompareTable>

- `justify-content: space-between`은 첫 아이템을 시작점, 마지막 아이템을 끝점에 붙이고 남는 공간을 아이템 사이에 똑같이 나눠요.
- `align-items`의 기본값 `stretch`는 높이(교차축 크기)를 정하지 않은 아이템을 컨테이너 높이만큼 늘려요.

두 가지 관점으로 기억해 보세요.

- **축 관점**: "justify는 주축, align은 교차축". 방향은 `flex-direction`을 보고 정해요.
- **질문 관점**: "아이템이 늘어선 방향으로 옮기고 싶나? 그럼 justify. 그와 수직으로 옮기고 싶나? 그럼 align."

### gap: 아이템 사이 간격

컨테이너에 `gap: 16px`를 주면 아이템과 아이템 **사이**에만 16px 간격이 생겨요. 아이템이 세 개면 간격은 두 군데예요. 컨테이너 가장자리와 첫·마지막 아이템 사이에는 간격이 생기지 않으니, 가장자리 여백이 필요하면 컨테이너에 `padding`을 줘요.
</Section>

<Section kind="examples">
첫 번째 예제는 부모에 `display: flex`와 `gap`을 준 모습이에요. 실행한 뒤 `display: flex`를 지우거나 `.item`으로 옮겨 보세요.

<RunnableExample id="container" lang="web" concepts={["css.flex.container", "css.flex.gap"]}>
```html
<style>
  .list {
    display: flex;
    gap: 12px;
    padding: 12px;
    background: #e5e7eb;
  }
  .item {
    padding: 12px;
    background: #fde68a;
    border: 2px solid #92400e;
  }
</style>
<div class="list">
  <div class="item">카드 1</div>
  <div class="item">카드 2</div>
  <div class="item">카드 <strong>3</strong></div>
</div>
```
</RunnableExample>
</Section>

<Section kind="walkthrough">
- `.list`가 플렉스 컨테이너가 되어, 바로 아래 자식인 `.item` 세 개가 한 줄로 놓여요. 원래 `div`는 블록이라 위아래로 쌓였을 거예요.
- 카드 사이에는 `gap: 12px`만큼 간격이 생겨요. 회색 가장자리와 카드 사이의 12px은 gap이 아니라 `.list`의 `padding`이 만든 거예요.
- 세 번째 카드 안의 `strong`은 `.list`의 손자라 아이템이 아니에요. 카드 안에서 글자처럼 흘러요.
- `display: flex`를 `.item`으로 옮기면 카드들은 다시 위아래로 쌓여요. 각 카드가 자기 안쪽 글자의 컨테이너가 될 뿐이에요.
</Section>

<Section kind="examples">
두 번째 예제를 실행하기 전에, 두 버튼이 회색 상자의 어디에 놓일지 먼저 예측해 보세요. 주축이 어느 방향인지부터 생각해요.

<RunnableExample id="column-justify" lang="web" predict predictKind="value" concepts={["css.flex.axes", "css.flex.justify-align"]}>
```html
<style>
  .panel {
    display: flex;
    flex-direction: column;
    justify-content: center;
    align-items: flex-start;
    height: 160px;
    background: #e5e7eb;
  }
  .btn {
    padding: 8px 12px;
    background: #2563eb;
    color: white;
  }
</style>
<div class="panel">
  <div class="btn">시작하기</div>
  <div class="btn">둘러보기</div>
</div>
```
</RunnableExample>
</Section>

<Section kind="walkthrough">
버튼 두 개는 **위아래로 쌓인 채 세로 가운데, 가로 왼쪽**에 놓여요.

| 단계 | 무엇을 보나요 | 결과 |
|---|---|---|
| 1 | `flex-direction: column` | 주축은 세로, 교차축은 가로 |
| 2 | `justify-content: center` (주축) | 세로 방향 가운데 |
| 3 | `align-items: flex-start` (교차축) | 가로 방향 시작점(왼쪽) |

`justify-content`를 "가로 정렬"로 외워 두면 이 예제에서 버튼이 가로 가운데로 갈 거라고 예상하게 돼요. 주축이 세로로 바뀌면 `justify-content`도 세로를 맡아요. `align-items`를 `center`로 바꿔 보면 버튼이 가로 가운데로도 옮겨져요.
</Section>

<Section kind="examples">
세 번째 예제는 실제 사이트의 헤더처럼 로고를 왼쪽, 버튼을 오른쪽 끝에 놓고 둘 다 세로 가운데로 맞춰요.

<RunnableExample id="header" lang="web" concepts={["css.flex.justify-align"]}>
```html
<style>
  .header {
    display: flex;
    justify-content: space-between;
    align-items: center;
    height: 64px;
    padding: 0 16px;
    background: #1f2937;
    color: white;
  }
  .login {
    padding: 6px 12px;
    background: #059669;
  }
</style>
<div class="header">
  <div>ProgInOne</div>
  <div class="login">로그인</div>
</div>
```
</RunnableExample>
</Section>

<Section kind="walkthrough">
- 주축은 가로(기본값 `row`)예요. `justify-content: space-between`이 로고를 왼쪽 끝, 버튼을 오른쪽 끝에 붙이고 남는 공간을 둘 사이에 몰아줘요.
- 세로는 교차축이라 `align-items: center`가 두 아이템을 64px 높이의 가운데에 맞춰요.
- 양 끝과 가장자리 사이의 16px은 `padding`이에요. `justify-content`나 `gap`은 가장자리 여백을 만들지 않아요.
</Section>

<Section kind="pitfalls">
<Pitfall misconception="css.mc.flex-on-children">
<Wrong>카드들을 나란히 놓고 싶으니 `.card`에 `display: flex`를 준다.</Wrong>
<Actual>각 카드가 자기 안쪽 내용의 컨테이너가 될 뿐, 카드들은 여전히 위아래로 쌓여요.</Actual>
<Right>`display: flex`는 나란히 놓을 요소들을 **감싼 부모**에 줘요. "누구의 자식들을 놓을까?"를 먼저 물어보세요.</Right>
</Pitfall>

<Pitfall misconception="css.mc.flex-affects-grandchildren">
<Wrong>`ul`에 `display: flex`를 줬으니 `li` 안의 `a`와 `span`까지 모두 한 줄로 늘어선다.</Wrong>
<Actual>플렉스 아이템은 `ul`의 바로 아래 자식인 `li`뿐이에요. `a`와 `span`은 `li` 안에서 원래대로 배치돼요.</Actual>
<Right>Flexbox는 한 단계만 영향을 줘요. 손자 요소도 나란히 놓고 싶다면 그 부모에 `display: flex`를 한 번 더 줘요.</Right>
</Pitfall>

<Pitfall misconception="css.mc.column-means-columns">
<Wrong>`flex-direction: column`을 주면 아이템이 신문의 단처럼 여러 열로 나란히 놓인다.</Wrong>
<Actual>아이템이 위에서 아래로 한 줄로 쌓여요. 열이 여러 개 생기지 않아요.</Actual>
<Right>`column`은 "주축을 세로로"라는 뜻이에요. 가로로 나란히 놓는 것은 기본값 `row`예요.</Right>
</Pitfall>

<Pitfall misconception="css.mc.justify-is-horizontal">
<Wrong>`justify-content: center`는 언제나 가로 가운데 정렬이다.</Wrong>
<Actual>`flex-direction: column`에서는 `justify-content: center`가 아이템을 **세로** 가운데로 옮겨요.</Actual>
<Right>`justify-content`는 주축 정렬이에요. 먼저 `flex-direction`으로 주축 방향을 확인하세요.</Right>
</Pitfall>

<Pitfall misconception="css.mc.justify-align-swap">
<Wrong>가로로 놓인 아이템을 세로 가운데로 맞추려고 `justify-content: center`를 쓴다.</Wrong>
<Actual>아이템이 가로 가운데로 모일 뿐, 세로 위치는 그대로예요.</Actual>
<Right>row에서 세로는 교차축이라 `align-items: center`가 맡아요. "늘어선 방향이면 justify, 수직 방향이면 align"으로 기억하세요.</Right>
</Pitfall>

<Pitfall misconception="css.mc.gap-adds-outer-edges">
<Wrong>`gap: 20px`를 주면 컨테이너 양 끝에도 20px 여백이 생긴다.</Wrong>
<Actual>gap은 아이템 사이에만 생겨요. 아이템이 세 개면 두 군데뿐이에요.</Actual>
<Right>가장자리 여백은 컨테이너의 `padding`으로 따로 줘요.</Right>
</Pitfall>
</Section>

<Section kind="in-practice">
웹 사이트의 내비게이션 막대는 Flexbox를 두 단계로 쓰는 대표적인 예예요.

```css
.nav {
  display: flex;
  justify-content: space-between; /* 로고는 왼쪽, 메뉴 묶음은 오른쪽 */
  align-items: center;            /* 세로 가운데 */
  padding: 12px 24px;             /* 가장자리 여백 */
}
.links {
  display: flex;                  /* 메뉴 링크들을 한 줄로 */
  gap: 16px;                      /* 링크 사이 간격 */
}
```

`.nav`의 아이템은 로고와 `.links` 두 개예요. 링크들은 `.nav`의 손자라서 `.links`에 `display: flex`를 한 번 더 줘야 나란히 놓여요. 이렇게 "큰 배치는 바깥 컨테이너, 작은 배치는 안쪽 컨테이너"로 나누는 방식은 카드 목록, 버튼 묶음, 폼의 한 줄 등 어디서나 볼 수 있어요.

<Callout kind="tip" title="개발자 도구의 flex 배지">
브라우저 개발자 도구(<Key>F12</Key>)의 요소 패널에서 플렉스 컨테이너 옆에 `flex` 배지가 보여요. 배지를 누르면 아이템과 gap이 화면에 표시되어 간격이 어디서 생겼는지 바로 알 수 있어요.
</Callout>

<Section kind="summary">
- 부모에 `display: flex`를 주면 부모는 플렉스 컨테이너, 바로 아래 자식들은 플렉스 아이템이 되어 한 줄로 놓여요.
- 아이템이 되는 것은 바로 아래 자식뿐이고, 손자 요소는 영향을 받지 않아요.
- 아이템이 늘어서는 방향이 주축, 그와 수직인 방향이 교차축이에요. `row`는 주축이 가로, `column`은 주축이 세로예요.
- `justify-content`는 주축, `align-items`는 교차축 방향으로 정렬해요.
- `gap`은 아이템 사이에만 간격을 만들고, 가장자리 여백은 `padding`으로 줘요.
</Section>
