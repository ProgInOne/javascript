<Section kind="objectives">
- `px`·`%`·`vw`로 정한 길이가 실제로 몇 px이 되는지 계산할 수 있어요.
- `rem`과 `em`이 기준으로 삼는 글자 크기를 구분하고, 중첩된 `em`의 크기를 계산할 수 있어요.
- 이름·16진수·`rgb()` 표기로 원하는 색을 쓰고, 서로 다른 표기가 같은 색인지 판단할 수 있어요.
</Section>

<Section kind="prerequisites" />

<Section kind="intro">
지금까지는 `width: 200px`처럼 길이를 늘 `px`로 썼어요. 그런데 실제로 페이지를 만들다 보면 이런 요구가 생겨요.

- "이 상자는 **부모의 절반** 너비였으면 좋겠어요." 부모 너비가 바뀌어도 늘 절반이어야 해요.
- "학습자가 브라우저 글자 크기를 키우면 **제목도 같이** 커졌으면 좋겠어요."
- "디자이너가 준 색이 `#2563eb`인데, 다른 곳에는 `rgb(...)`로 적혀 있어요. 같은 색일까요?"

`px`만으로는 이런 요구를 맞추기 어려워요. CSS에는 **무엇을 기준으로 크기를 정할지** 고를 수 있는 여러 단위가 있고, 색도 여러 방법으로 쓸 수 있어요. 이 단원에서는 각 단위가 무엇을 기준으로 하는지, 색 표기를 어떻게 읽는지 배워요.
</Section>

<Section kind="principle">
### 길이 단위: 무엇을 기준으로 하나요

| 단위 | 기준 | 예 |
|---|---|---|
| `px` | 고정된 크기 | `width: 200px` → 언제나 200px |
| `%` | **부모** 요소의 크기(너비는 부모 content 영역의 너비) | 부모 content가 400px이면 `width: 50%` → 200px |
| `vw` | **화면(뷰포트)** 너비의 1/100 | 화면이 1280px이면 `width: 50vw` → 640px |
| `rem` | **루트(`html`) 요소**의 글자 크기 | 루트가 16px이면 `2rem` → 32px |
| `em` | 그 요소의 글자 크기 (`font-size`에 쓰면 **부모**의 글자 크기) | 부모가 20px이면 `font-size: 2em` → 40px |

브라우저의 기본 글자 크기는 보통 `16px`이에요. 그래서 따로 정하지 않으면 `1rem`은 16px이에요.

0이 아닌 길이에는 **단위를 꼭 붙여요.** `width: 200;`처럼 단위를 빼면 브라우저는 무엇의 200인지 알 수 없어서 그 선언을 무시해요. 단위를 빼도 되는 건 `0`(무엇이든 0은 0이니까)과, 나중에 배울 `line-height`처럼 단위 없는 숫자를 받는 속성뿐이에요.

### rem과 em의 차이

`rem`은 "root em"의 줄임말이에요. 이름 그대로 **루트**의 글자 크기만 보니까 어디에 써도 같은 크기가 돼요.

`em`은 **가까운 곳**을 봐요. `font-size`에 `em`을 쓰면 부모의 글자 크기가 기준이에요. 그래서 `em`으로 정한 요소 안에 또 `em`으로 정한 요소가 있으면 크기가 **계속 곱해져요**.

```text
html          16px
└ .outer      font-size: 1.5em → 16 × 1.5 = 24px
  └ .inner    font-size: 1.5em → 24 × 1.5 = 36px   (rem이었다면 24px)
```

### 색 표기

같은 색을 여러 방법으로 쓸 수 있어요.

<CompareTable columns={["이름", "16진수", "rgb()"]}>
<Row label="빨강">`red` | `#ff0000` | `rgb(255 0 0)`</Row>
<Row label="검정">`black` | `#000000` | `rgb(0 0 0)`</Row>
<Row label="흰색">`white` | `#ffffff` | `rgb(255 255 255)`</Row>
<Row label="주황">(이름 없음) | `#ff8000` | `rgb(255 128 0)`</Row>
</CompareTable>

- **이름**: `red`, `white`, `tomato`처럼 정해진 영어 이름이에요. 쉽지만 고를 수 있는 색이 적어요.
- **`rgb(빨강 초록 파랑)`**: 빛의 세 가지 색을 섞는 양을 **0부터 255까지** 숫자로 써요. 0은 그 빛이 전혀 없고, 255가 가장 강해요. 셋 다 255면 흰색, 셋 다 0이면 검정이에요. `rgb(255, 0, 0)`처럼 쉼표로 나눠 써도 같아요.
- **16진수 `#rrggbb`**: 같은 세 값을 두 자리씩 16진수로 써요. `00`이 0, `ff`가 255, `80`이 128이에요. `#fff`처럼 세 자리로 줄여 쓰면 각 자리를 두 번씩 쓴 것(`#ffffff`)과 같아요.
</Section>

<Section kind="examples">
첫 번째 예제를 실행하기 전에, 노란 상자가 몇 px 너비로 보일지 먼저 계산해 보세요. 파란 부모 상자의 너비는 `400px`이에요.

<RunnableExample id="percent-predict" lang="web" predict predictKind="value" concepts={["css.units.length"]}>
```html
<style>
  .parent {
    width: 400px;
    background: #bfdbfe;
  }
  .child {
    width: 50%;
    background: #fde68a;
  }
</style>
<div class="parent">
  <div class="child">width: 50%</div>
</div>
```
</RunnableExample>
</Section>

<Section kind="walkthrough">
노란 상자는 **200px**로 보여요. 미리보기 창이 얼마나 넓든 상관없어요.

- `%`는 화면이 아니라 **부모**를 기준으로 해요. 부모 `.parent`의 content 너비가 400px이니 그 50%인 200px이에요.
- 화면 너비의 절반이 필요했다면 `50vw`를 써야 해요. `vw`만 화면(뷰포트) 너비를 기준으로 해요.
</Section>

<Section kind="examples">
두 번째 예제는 같은 `1.5`라는 값을 `em`과 `rem`으로 써서 중첩해 봤어요. 실행한 뒤 두 줄의 글자 크기를 비교해 보세요.

<RunnableExample id="em-vs-rem" lang="web" concepts={["css.units.rem-em"]}>
```html
<style>
  .em {
    font-size: 1.5em;
  }
  .rem {
    font-size: 1.5rem;
  }
</style>
<div class="em">
  em 바깥 (24px)
  <div class="em">em 안쪽 (36px)</div>
</div>
<div class="rem">
  rem 바깥 (24px)
  <div class="rem">rem 안쪽 (24px)</div>
</div>
```
</RunnableExample>
</Section>

<Section kind="walkthrough">
- 첫 `.em`은 부모(`body`, 16px)의 1.5배인 24px이에요. 그 안의 `.em`은 부모가 24px이니 다시 1.5배인 36px이 돼요.
- `.rem`은 둘 다 루트(`html`, 16px)의 1.5배라서 바깥이든 안쪽이든 24px이에요.
- 그래서 글자 크기는 보통 `rem`으로 정해요. 어디에 두어도 크기가 예측 가능하기 때문이에요.
</Section>

<Section kind="examples">
세 번째 예제는 같은 주황색을 세 가지 방법으로 쓰고, 단위를 뺀 선언이 어떻게 되는지 보여 줘요.

<RunnableExample id="colors-and-units" lang="web" concepts={["css.colors.notation", "css.units.length"]}>
```html
<style>
  .chip {
    width: 160px;
    padding: 8px;
    margin-bottom: 6px;
  }
  .hex {
    background: #ff8000;
  }
  .rgb {
    background: rgb(255 128 0);
  }
  .dark {
    background: rgb(128 64 0);
    color: white;
  }
  .no-unit {
    width: 160;
    background: #bfdbfe;
  }
</style>
<div class="chip hex">#ff8000</div>
<div class="chip rgb">rgb(255 128 0)</div>
<div class="chip dark">rgb(128 64 0)</div>
<div class="no-unit">width: 160 (단위 없음)</div>
```
</RunnableExample>
</Section>

<Section kind="walkthrough">
- 위의 두 상자는 **같은 색**이에요. `ff`는 255, `80`은 128, `00`은 0이라서 `#ff8000`과 `rgb(255 128 0)`은 같은 값을 다르게 쓴 거예요.
- 세 번째 상자는 각 값을 절반쯤으로 줄였더니 **어두운** 주황(갈색)이 됐어요. 숫자가 작을수록 빛이 약해서 어두워져요.
- 마지막 상자는 `width: 160;`에 단위가 없어서 선언이 무시됐어요. 그래서 블록 요소의 기본 동작대로 부모 너비를 꽉 채워요.
</Section>

<Section kind="pitfalls">
<Pitfall misconception="css.mc.percent-of-screen">
<Wrong>`width: 50%`는 언제나 화면 너비의 절반이다.</Wrong>
<Actual>`width`의 `%`는 **부모** 요소의 content 너비를 기준으로 해요. 부모가 400px이면 50%는 200px이에요.</Actual>
<Right>화면 너비를 기준으로 하고 싶으면 `vw`를 써요. `%`를 계산할 때는 먼저 부모의 너비를 확인해요.</Right>
</Pitfall>

<Pitfall misconception="css.mc.unitless-length">
<Wrong>`width: 200;`처럼 단위를 빼도 브라우저가 알아서 200px로 처리한다.</Wrong>
<Actual>0이 아닌 길이에 단위가 없으면 잘못된 값이라서 그 선언 전체가 무시돼요.</Actual>
<Right>`200px`, `50%`, `2rem`처럼 단위를 붙여요. 단위를 빼도 되는 건 `0`과 `line-height` 같은 일부 속성뿐이에요.</Right>
</Pitfall>

<Pitfall misconception="css.mc.em-same-as-rem">
<Wrong>`em`과 `rem`은 같아서 `2em`은 어디서나 32px이다.</Wrong>
<Actual>`font-size`에 쓴 `em`은 부모의 글자 크기를 기준으로 해요. 부모가 20px이면 `2em`은 40px이고, 중첩되면 계속 곱해져요.</Actual>
<Right>어디서나 같은 크기가 필요하면 루트를 기준으로 하는 `rem`을 써요. `em`을 계산할 때는 부모의 글자 크기부터 구해요.</Right>
</Pitfall>

<Pitfall misconception="css.mc.rgb-max-100">
<Wrong>`rgb()`의 값은 0부터 100까지이라서 `rgb(100 0 0)`이 가장 진한 빨강이다.</Wrong>
<Actual>값의 범위는 0부터 255까지예요. `rgb(100 0 0)`은 꽤 어두운 빨강이에요.</Actual>
<Right>가장 진한 빨강은 `rgb(255 0 0)`, 16진수로는 `#ff0000`이에요. 16진수 `ff`도 255라는 점을 함께 기억해요.</Right>
</Pitfall>
</Section>

<Section kind="in-practice">
실제 사이트의 CSS에서는 단위를 이렇게 나눠 쓰는 경우가 많아요.

```css
html {
  font-size: 100%; /* 학습자가 브라우저에서 정한 글자 크기를 존중해요 */
}
h1 {
  font-size: 2rem; /* 루트의 2배 */
}
.container {
  width: 90%; /* 부모의 90% */
  max-width: 960px; /* 아무리 넓어도 960px까지만 */
}
.brand {
  color: #2563eb;
}
```

- 글자 크기는 `rem`으로 정해 두면, 학습자가 브라우저 설정에서 기본 글자 크기를 키웠을 때 페이지 전체가 같은 비율로 커져요.
- 상자 너비는 `%`로 부모에 맞추고, 너무 넓어지지 않게 `max-width`를 `px`로 함께 써요.
- 색은 디자인 도구에서 복사한 16진수를 그대로 쓰는 경우가 가장 많아요.
</Section>

<Section kind="summary">
- `px`는 고정 크기, `%`는 부모 크기, `vw`는 화면 너비의 1/100을 기준으로 해요.
- 0이 아닌 길이에 단위를 빼면 선언이 무시돼요.
- `rem`은 루트(`html`)의 글자 크기, `font-size`에 쓴 `em`은 부모의 글자 크기를 기준으로 해요. `em`은 중첩되면 계속 곱해져요.
- 색은 이름, 16진수 `#rrggbb`, `rgb(빨강 초록 파랑)`으로 쓸 수 있어요.
- `rgb()`의 각 값은 0부터 255까지이고, 16진수 `00`부터 `ff`까지도 같은 범위예요.
</Section>
