<Section kind="objectives">
- `str[i]`로 원하는 위치의 글자를 읽고, `length`로 글자 수와 마지막 글자의 인덱스를 구할 수 있어요.
- 범위 밖 인덱스를 읽으면 `undefined`가 나온다는 것을 알고, 반복으로 글자를 하나씩 볼 때 범위를 맞게 정할 수 있어요.
- 문자열의 글자를 인덱스로 바꿀 수 없다는 것을 알고, 새 문자열을 만들어 다시 대입하는 코드로 고칠 수 있어요.
- 템플릿 리터럴의 `${}`로 변수와 식의 값을 문자열에 끼워 넣고, 따옴표 문자열과 무엇이 다른지 설명할 수 있어요.
</Section>

<Section kind="intro">
회원 가입 화면을 떠올려 볼게요. 닉네임이 2글자 이상인지 확인하고, 이름의 첫 글자만 따서 프로필 동그라미에 보여 주고, "민지님, 환영해요!"처럼 이름을 넣은 인사말을 만들어야 해요.

지금까지는 문자열을 통째로만 다뤘어요. `"민지" + "님"`처럼 이어 붙이거나 그대로 출력하는 정도였죠. 그런데 위의 일을 하려면 문자열 **안의 글자 하나하나**를 다룰 수 있어야 해요. 몇 글자인지 세고, 몇 번째 글자를 꺼내고, 값을 문자열 사이에 깔끔하게 끼워 넣어야 하니까요.

이 단원에서는 문자열의 글자에 붙은 번호(인덱스)와 글자 수(`length`)를 배우고, 문자열은 한번 만들면 바꿀 수 없다는 중요한 성질을 확인한 뒤, `+`보다 읽기 쉽게 값을 끼워 넣는 **템플릿 리터럴**을 배워요.
</Section>

<Section kind="principle">
### 글자마다 0부터 시작하는 번호가 있어요

문자열은 글자가 한 줄로 늘어선 것이에요. 글자마다 **인덱스**라는 번호가 붙어 있고, 번호는 **0부터** 시작해요. 문자열 뒤에 대괄호와 번호를 쓰면 그 자리의 글자를 꺼낼 수 있어요.

```js
const word = "coffee";
console.log(word[0]); // c
console.log(word[2]); // f
```

`"coffee"`의 칸을 그려 보면 이래요.

| 인덱스 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 글자 | c | o | f | f | e | e |

왜 0부터일까요? 인덱스는 "몇 번째"가 아니라 **"맨 앞에서 몇 칸 떨어져 있나"** 로 읽으면 쉬워요. 첫 글자는 맨 앞에서 0칸 떨어져 있으니 0번, 두 번째 글자는 1칸 떨어져 있으니 1번이에요.

### length는 글자 수예요

`word.length`는 문자열의 글자 수예요. 공백과 기호도 한 글자로 세요. 괄호 없이 쓴다는 점을 눈여겨보세요. `length`는 문자열이 가진 **값**이라서, 부르는 기능(함수)처럼 `()`를 붙이지 않아요.

```js
console.log("coffee".length); // 6
console.log("안녕 하세요".length); // 6 (공백도 한 글자)
console.log("".length); // 0 (빈 문자열)
```

인덱스와 `length`를 같이 보면 중요한 관계가 보여요.

- 글자가 6개이면 인덱스는 0부터 5까지예요. **마지막 인덱스는 `length - 1`** 이에요.
- 그래서 마지막 글자는 `word[word.length - 1]`로 꺼내요. 글자 수가 달라져도 항상 맞아요.
- `word[word.length]`는 마지막 글자 **다음** 칸이라 아무 글자도 없어요.

### 범위 밖 인덱스는 undefined예요

없는 칸을 읽으면 오류가 나지 않고 `undefined`가 나와요(모듈 2에서 배운 "값이 아직 없음"이에요).

```js
const word = "coffee";
console.log(word[6]); // undefined
console.log(word[100]); // undefined
```

오류가 나지 않는다는 점이 오히려 위험해요. 실수가 조용히 숨어 있다가 화면에 `undefined`라는 글자로 나타나거든요.

### 반복으로 글자를 하나씩 보기

모듈 5에서 배운 `for`와 인덱스를 합치면 글자를 하나씩 볼 수 있어요. 반복 변수 `i`가 0부터 `length - 1`까지 가면 돼요. 조건은 `i < word.length`예요.

```js
const word = "cat";
for (let i = 0; i < word.length; i++) {
  console.log(i + "번: " + word[i]);
}
// 0번: c
// 1번: a
// 2번: t
```

### 문자열은 바꿀 수 없어요

글자를 꺼내 읽을 수는 있지만, **그 자리에 다른 글자를 넣을 수는 없어요.** 문자열은 한번 만들면 내용을 바꿀 수 없는 값이에요. 이런 성질을 **불변(immutable)** 이라고 해요.

```js
let pet = "cat";
pet[0] = "b"; // TypeError가 나요
```

ProgInOne은 코드를 엄격 모드로 실행해서, 문자열의 글자에 대입하면 `TypeError: Cannot assign to read only property '0' of string 'cat'`("읽기만 할 수 있는 칸에 대입할 수 없어요")이 나요.

글자를 바꾸고 싶다면 **새 문자열을 만들어서 변수에 다시 대입**해요. 변수 `pet`이 가리키는 문자열이 새것으로 바뀌는 것이지, 원래 `"cat"`의 글자가 바뀌는 것은 아니에요.

```js
let pet = "cat";
pet = "b" + pet[1] + pet[2]; // 새 문자열 "bat"을 만들어 다시 대입
console.log(pet); // bat
```

<Callout kind="note" title="let이면 바꿀 수 있는 것 아닌가요?">
`let`은 "변수에 **다른 값을 다시 대입**할 수 있다"는 뜻이에요. 문자열 안의 글자를 바꿀 수 있다는 뜻이 아니에요. 위 코드도 `pet[0]`을 바꾼 게 아니라 `pet =`으로 새 문자열을 대입했어요. `const`로 만든 변수였다면 다시 대입하는 것도 안 돼요.
</Callout>

### 템플릿 리터럴: 값을 끼워 넣는 문자열

지금까지는 문자열과 값을 `+`로 이어 붙였어요.

```js
const name = "민지";
const count = 3;
console.log(name + "님, 장바구니에 " + count + "개가 있어요");
```

따옴표와 `+`가 번갈아 나와서 읽기 어렵고, 공백을 빠뜨리기도 쉬워요. **템플릿 리터럴**은 따옴표 대신 **백틱**(`` ` ``, 키보드에서 숫자 1 왼쪽에 있는 키)으로 감싼 문자열이에요. 그 안에서는 `${}` 안에 쓴 값이 그 자리에 들어가요.

```js
const name = "민지";
const count = 3;
console.log(`${name}님, 장바구니에 ${count}개가 있어요`);
```

템플릿 리터럴의 규칙은 세 가지예요.

- `${}`가 값으로 바뀌는 것은 **백틱 문자열 안에서만**이에요. 작은따옴표·큰따옴표 문자열 안의 `${name}`은 그냥 글자예요.
- `${}` 안에는 변수뿐 아니라 `price * qty`, `word.length` 같은 **식**도 쓸 수 있어요. 계산한 결과가 들어가요.
- 백틱 문자열 안에서 줄을 바꾸면 줄바꿈도 그대로 문자열에 들어가요.

<CompareTable columns={["따옴표 문자열", "템플릿 리터럴"]}>
<Row label="감싸는 기호">`"..."` 또는 `'...'` | 백틱 `` `...` ``</Row>
<Row label="값 끼워 넣기">`+`로 이어 붙임 | `${값}`을 그 자리에 씀</Row>
<Row label="${name}을 쓰면">글자 그대로 `${name}` | `name`의 값</Row>
<Row label="줄바꿈">그대로 쓸 수 없음 | 그대로 들어감</Row>
</CompareTable>

<Section kind="pitfalls">
<Pitfall misconception="js.mc.index-starts-at-one">
<Wrong>첫 글자는 `str[1]`로 읽는다. 사람이 "첫째"를 1로 세니까.</Wrong>
<Actual>첫 번째 예제에서 `city[1]`은 `S`가 아니라 두 번째 글자 `e`였어요.</Actual>
<Right>인덱스는 "맨 앞에서 몇 칸 떨어져 있나"예요. 첫 글자는 `str[0]`, n번째 글자는 `str[n - 1]`이에요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.last-index-is-length">
<Wrong>글자가 5개이면 마지막 글자는 `str[5]`, 즉 `str[str.length]`다.</Wrong>
<Actual>첫 번째 예제에서 `city[city.length]`는 `undefined`였어요. 인덱스가 0부터라서 5글자의 인덱스는 0~4예요.</Actual>
<Right>마지막 글자는 `str[str.length - 1]`이에요. 반복으로 글자를 볼 때도 조건은 `i <= str.length`가 아니라 `i < str.length`예요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.out-of-range-index-throws">
<Wrong>없는 인덱스를 읽으면 오류가 나서 알려 준다.</Wrong>
<Actual>`"coffee"[100]`은 오류 없이 `undefined`예요. 그래서 실수해도 프로그램이 계속 돌다가, 출력에 `undefined`라는 글자가 섞여 나와요.</Actual>
<Right>범위 밖 인덱스는 `undefined`예요. 출력에 `undefined`가 보이면 인덱스가 `length` 이상이 되지 않았는지 먼저 확인해요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.length-is-method">
<Wrong>글자 수는 `str.length()`처럼 괄호를 붙여 구한다.</Wrong>
<Actual>`"coffee".length()`를 실행하면 `TypeError: "coffee".length is not a function`이 나요. `length`는 숫자 값이라 부를 수 없어요.</Actual>
<Right>`length`는 괄호 없이 `str.length`로 읽어요. 다음 단원에서 배울 `toUpperCase()` 같은 메서드는 기능이라 괄호가 필요해요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.string-index-assign">
<Wrong>`let word = "cat"; word[0] = "b";`를 실행하면 `word`가 `"bat"`이 된다. `let`으로 만들었으니 바꿀 수 있다.</Wrong>
<Actual>세 번째 예제에서 `grade[0] = "A"`는 `TypeError`를 냈어요. 엄격 모드가 아니어도 문자열은 바뀌지 않아요(조용히 무시돼요).</Actual>
<Right>문자열은 바꿀 수 없어요. `word = "b" + word[1] + word[2];`처럼 새 문자열을 만들어 변수에 다시 대입해요. `let`이 허락하는 것은 이 "다시 대입"이에요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.template-in-normal-quotes">
<Wrong>큰따옴표 문자열 안에 `${name}`을 써도 `name`의 값이 들어간다.</Wrong>
<Actual>네 번째 예제의 3번 줄은 `${menu}: ${price}원`을 글자 그대로 출력했어요.</Actual>
<Right>`${}`는 백틱으로 감싼 템플릿 리터럴 안에서만 값으로 바뀌어요. 여는 기호와 닫는 기호가 모두 백틱인지 확인해요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.template-missing-braces">
<Wrong>백틱 문자열 안에서는 `$total`처럼 `$` 뒤에 이름만 써도 값이 들어간다.</Wrong>
<Actual>`` `합계: $total원` ``은 `합계: $total원`이 글자 그대로 출력돼요. 중괄호가 없으면 `$`도 그냥 글자예요.</Actual>
<Right>값을 넣을 자리는 반드시 `${total}`처럼 `$`와 중괄호로 감싸요.</Right>
</Pitfall>
</Section>

<Section kind="in-practice">
게시판 글쓰기 화면에는 "120/200자"처럼 지금까지 쓴 글자 수를 보여 주는 표시가 자주 있어요. `length`와 템플릿 리터럴만 있으면 만들 수 있어요.

```js
const limit = 200;
const text = "오늘 처음으로 문자열을 배웠어요";
const remain = limit - text.length;
console.log(`${text.length}/${limit}자 (남은 글자 ${remain}자)`);
// 17/200자 (남은 글자 183자)
```

- `text.length`는 공백까지 센 글자 수예요. 실제 서비스도 공백을 글자 수에 넣는 경우가 많아요.
- 메시지는 템플릿 리터럴로 만들어서 `+`와 따옴표가 섞이지 않아요.
- 연습 문제에서 입력할 때마다 이 표시가 바뀌는 화면을 직접 만들어 봐요.
</Section>

<Section kind="summary">
- 문자열의 글자는 0부터 시작하는 인덱스로 `str[i]`처럼 읽어요. 첫 글자는 `str[0]`이에요.
- `str.length`는 공백까지 센 글자 수이고, 괄호 없이 써요. 마지막 글자는 `str[str.length - 1]`이에요.
- 범위 밖 인덱스를 읽으면 오류 대신 `undefined`가 나와요. 반복의 조건은 `i < str.length`로 써요.
- 문자열은 바꿀 수 없어요. `str[0] = "A"`는 엄격 모드에서 `TypeError`예요. 새 문자열을 만들어 다시 대입해요.
- 백틱으로 감싼 템플릿 리터럴 안에서는 `${}` 안의 값이나 식의 결과가 그 자리에 들어가고, 줄바꿈도 그대로 들어가요.
