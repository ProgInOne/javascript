<Section kind="objectives">
- `조건 ? 값1 : 값2`가 만드는 값을 예측하고, 그 값을 변수에 넣거나 바로 출력할 수 있어요.
- `if-else`로 값을 고르는 코드를 조건 연산자 한 줄로 바꿔 쓸 수 있어요.
- 조건 연산자를 문장처럼 쓰거나 결과를 버리는 버그, 괄호가 없어 생기는 우선순위 버그를 고칠 수 있어요.
</Section>

<Section kind="prerequisites" />

<Section kind="intro">
회원이면 배송비가 0원, 아니면 3000원인 쇼핑몰이 있어요. 지금까지 배운 방법으로는 이렇게 써요.

```js
let fee;
if (isMember) {
  fee = 0;
} else {
  fee = 3000;
}
```

다섯 줄이나 되지만 하는 일은 **"두 값 중 하나를 골라 `fee`에 넣기"** 하나뿐이에요. `fee`를 미리 만들어 두고 두 블록에서 각각 대입해야 해서, 한쪽에서 대입을 빠뜨리는 실수도 생기기 쉬워요.

이렇게 조건에 따라 **값**을 고르는 일은 **조건 연산자**로 한 줄에 쓸 수 있어요.

```js
const fee = isMember ? 0 : 3000;
```

피연산자가 세 개(조건, 값1, 값2)라서 **삼항 연산자**라고도 불러요.
</Section>

<Section kind="principle">
### 조건 ? 값1 : 값2

```js
조건 ? 참일 때의 값 : 거짓일 때의 값
```

1. `?` 앞의 **조건**을 계산해요.
1. 조건이 참이면 `?`와 `:` 사이의 값이, 거짓이면 `:` 뒤의 값이 **식 전체의 결과**가 돼요.
1. 고르지 않은 쪽은 계산하지도 않아요.

`if-else`는 "어떤 **문장들**을 실행할지" 고르는 **문**(statement)이고, 조건 연산자는 "어떤 **값**이 될지" 고르는 **식**(expression)이에요. 식은 값이 되므로 값이 들어갈 수 있는 곳 어디에나 쓸 수 있어요.

```js
// 변수에 넣기
const fee = isMember ? 0 : 3000;
// 바로 출력하기
console.log(stock > 0 ? "판매 중" : "품절");
// 다른 식 안에 쓰기
const label = "배송비: " + (isMember ? 0 : 3000);
```

| 하고 싶은 일 | 알맞은 도구 |
|---|---|
| 조건에 따라 **값 하나**를 골라 쓰기 | 조건 연산자 |
| 조건에 따라 **여러 문장**을 실행하기, 갈래가 셋 이상이기 | `if … else if … else` |

### 식이라서 생기는 규칙

**결과를 받아서 써야 해요.** 조건 연산자는 값을 만들기만 해요. `stock > 0 ? "판매 중" : "품절";`처럼 한 줄에 그냥 쓰면 값이 만들어졌다가 바로 버려지고 아무 일도 일어나지 않아요. 변수에 대입하거나 `console.log`에 넘겨야 해요.

**`?`와 `:` 뒤에는 값만 와요.** `const`·`let` 선언이나 `if` 같은 문장은 넣을 수 없어요. `isRaining ? const item = "우산" : const item = "모자";`는 `SyntaxError`예요. 값을 고른 뒤 한 번에 받아요: `const item = isRaining ? "우산" : "모자";`.

**다른 식 안에서는 괄호로 감싸요.** 조건 연산자는 우선순위가 아주 낮아서 `+`, `>=` 같은 연산자가 먼저 계산돼요.

```js
const score = 75;
console.log("결과: " + score >= 60 ? "합격" : "불합격"); // 불합격
console.log("결과: " + (score >= 60 ? "합격" : "불합격")); // 결과: 합격
```

첫 줄은 `"결과: " + score`가 먼저 이어 붙여져 `"결과: 75"`가 되고, 이 문자열과 `60`을 비교한 `"결과: 75" >= 60`이 조건이 돼요. 이 비교는 `false`라서(모듈 3에서 배운 대로 `"결과: 75"`는 숫자로 바꾸면 `NaN`이에요) 결과는 `불합격`이고, 앞의 `"결과: "`도 사라져요. 괄호로 감싸면 조건 연산자가 먼저 값이 되고, 그 값이 이어 붙여져요.

<Reveal title="조건 연산자를 이어 쓰면">
`:` 뒤에 또 조건 연산자를 써서 세 갈래로 나눌 수도 있어요.

```js
const size = height >= 180 ? "L" : height >= 165 ? "M" : "S";
```

뒤쪽부터 묶여서 `height >= 180 ? "L" : (height >= 165 ? "M" : "S")`로 읽혀요. 줄을 나눠 쓰면 `else if` 체인처럼 보여요. 하지만 갈래가 많아지면 읽기 어려우니 셋까지만 쓰고, 그보다 많으면 `else if` 체인을 써요.
</Reveal>
</Section>

<Section kind="examples">
첫 번째 예제예요. `label`과 출력에 어떤 값이 들어갈지 예측해 보세요.

<RunnableExample id="member-fee" lang="js" predict predictKind="console" concepts={["js.control.ternary"]}>
```js
const isMember = false;
const fee = isMember ? 0 : 3000;
console.log("배송비:", fee);
console.log(fee === 0 ? "무료 배송" : "유료 배송");
```
</RunnableExample>
</Section>

<Section kind="walkthrough">
```text
배송비: 3000
유료 배송
```

- 2번 줄: 조건 `isMember`가 `false`라서 `:` 뒤의 `3000`이 식의 값이 되고, `fee`에 들어가요.
- 4번 줄: `fee === 0`은 `false`라서 `"유료 배송"`이 식의 값이 되고, 그 값이 `console.log`로 넘어가요.

`isMember`를 `true`로 바꾸면 `배송비: 0`, `무료 배송`이 나와요. 두 줄 모두 if-else로 쓰면 각각 다섯 줄이 필요했을 거예요.
</Section>

<Section kind="examples">
두 번째 예제는 괄호를 빠뜨린 코드와 감싼 코드를 비교해요. 두 줄의 출력을 예측해 보세요.

<RunnableExample id="precedence" lang="js" predict predictKind="console" concepts={["js.control.ternary"]}>
```js
const count = 1;
console.log("포장: " + count > 1 ? "묶음" : "낱개");
console.log("포장: " + (count > 1 ? "묶음" : "낱개"));
```
</RunnableExample>
</Section>

<Section kind="walkthrough">
```text
낱개
포장: 낱개
```

- 2번 줄: `+`가 먼저 계산돼서 `"포장: 1"`이 만들어지고, 그다음 `"포장: 1" > 1`이 조건이 돼요. 이 문자열은 숫자로 바꾸면 `NaN`이라 비교 결과는 `false`, 식 전체의 값은 `"낱개"`예요. 앞에 이어 붙이려던 `"포장: "`은 조건에 쓰이고 사라졌어요.
- 3번 줄: 괄호 안의 조건 연산자가 먼저 `"낱개"`가 되고, 그 값이 `"포장: "` 뒤에 이어 붙여져요.

조건 연산자를 다른 식 안에 쓸 때는 **항상 괄호로 감싸요.** 결과가 맞더라도 읽는 사람이 계산 순서를 헷갈리지 않아요.
</Section>

<Section kind="examples">
세 번째 예제는 if-else를 조건 연산자로 바꾼 코드예요. 두 방식의 출력이 같은지 실행해 보세요.

<RunnableExample id="if-to-ternary" lang="js" concepts={["js.control.ternary", "js.control.if"]}>
```js
const battery = 15;

// if-else로 값 고르기
let iconA;
if (battery <= 20) {
  iconA = "빨간 배터리";
} else {
  iconA = "초록 배터리";
}

// 조건 연산자로 값 고르기
const iconB = battery <= 20 ? "빨간 배터리" : "초록 배터리";

console.log(iconA);
console.log(iconB);
```
</RunnableExample>
</Section>

<Section kind="walkthrough">
```text
빨간 배터리
빨간 배터리
```

두 방식 모두 `battery <= 20`이 참이라 `"빨간 배터리"`를 골랐어요. 조건 연산자 쪽은 값을 고르는 일이 한 줄에 드러나고, 처음부터 `const`로 만들 수 있어요. if-else 쪽은 변수를 먼저 `let`으로 만들고 두 블록에서 각각 대입해야 해요.

반대로 조건에 따라 여러 문장을 실행해야 하면(예: 경고를 출력하고 절전 모드를 켜기) if-else가 알맞아요.
</Section>

<Section kind="pitfalls">
<Pitfall misconception="js.mc.ternary-as-statement">
<Wrong>조건 연산자는 if-else의 줄임말이라서, `isRaining ? const item = "우산" : const item = "모자";`처럼 각 자리에 아무 문장이나 넣을 수 있다.</Wrong>
<Actual>`?`와 `:` 뒤에는 값(식)만 올 수 있어요. 변수 선언 같은 문장을 넣으면 `SyntaxError: Unexpected token 'const'`가 나요.</Actual>
<Right>값을 고른 뒤 한 번에 받아요: `const item = isRaining ? "우산" : "모자";`. 고른 값이 아니라 실행할 일을 고르고 싶다면 if-else를 써요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.ternary-result-discarded">
<Wrong>`stock > 0 ? "판매 중" : "품절";`이라고 쓰면 고른 값이 어딘가에 저장되거나 화면에 보인다.</Wrong>
<Actual>조건 연산자는 값을 만들기만 해요. 받는 곳이 없으면 만들어진 값은 바로 버려지고, 오류도 나지 않아 아무 일도 일어나지 않아요.</Actual>
<Right>결과를 변수에 대입하거나(`status = stock > 0 ? "판매 중" : "품절";`) `console.log`에 넘겨요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.ternary-precedence">
<Wrong>`"결과: " + score >= 60 ? "합격" : "불합격"`은 `"결과: "` 뒤에 `합격`이나 `불합격`을 붙인다.</Wrong>
<Actual>조건 연산자는 우선순위가 아주 낮아서 `+`와 `>=`가 먼저 계산돼요. `"결과: " + score`가 먼저 만들어지고, 그 문자열과 60을 비교한 값이 조건이 돼요. 그래서 결과는 `"불합격"` 하나뿐이고 `"결과: "`는 사라져요.</Actual>
<Right>다른 식 안에 쓸 때는 `"결과: " + (score >= 60 ? "합격" : "불합격")`처럼 조건 연산자를 괄호로 감싸요.</Right>
</Pitfall>
</Section>

<Section kind="in-practice">
화면에 보여 줄 글자를 조건에 따라 살짝 바꿀 때 조건 연산자를 많이 써요.

```js
const isLoggedIn = true;
const cartCount = 0;

const buttonText = isLoggedIn ? "로그아웃" : "로그인";
const cartText = cartCount > 0 ? "장바구니 (" + cartCount + ")" : "장바구니가 비었어요";

console.log(buttonText);
console.log(cartText);
```

- 로그인 상태에 따라 버튼 글자를 바꾸고, 담은 상품이 있으면 개수를, 없으면 안내 문구를 보여 줘요.
- 실제 웹 화면을 만드는 도구(React 같은 프레임워크)에서는 화면의 일부를 조건에 따라 고를 때 문(if)을 쓸 수 없는 자리가 많아서, 조건 연산자가 아주 자주 쓰여요.
</Section>

<Section kind="summary">
- `조건 ? 값1 : 값2`는 조건이 참이면 값1, 거짓이면 값2가 되는 **식**이에요.
- 식이라서 변수에 넣거나, `console.log`에 넘기거나, 다른 식 안에 쓸 수 있어요. 결과를 받지 않으면 그냥 버려져요.
- `?`와 `:` 뒤에는 값만 쓸 수 있어요. 선언이나 if 같은 문장은 넣을 수 없어요.
- 우선순위가 낮으니 다른 식 안에서는 괄호로 감싸요.
- 값 하나를 고를 때는 조건 연산자, 여러 문장을 실행하거나 갈래가 많을 때는 if-else를 써요.
</Section>
