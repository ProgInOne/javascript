<Section kind="objectives">
- 브라우저가 HTML을 DOM 트리로 만들고, JavaScript는 파일이 아니라 이 트리를 바꾼다는 것을 설명할 수 있어요.
- `querySelector`와 `querySelectorAll`로 CSS 선택자에 맞는 요소를 찾고, 찾지 못하면 `null`이 된다는 것을 알고 스크립트 위치를 바르게 정할 수 있어요.
- `textContent`로 요소의 글자를 읽고 바꿀 수 있어요.
- `classList`와 `style`로 요소의 모양을 바꾸고, `createElement`와 `append`로 새 요소를 만들어 화면에 붙일 수 있어요.
</Section>

<Section kind="intro">
지금까지 만든 프로그램은 결과를 모두 콘솔에 출력했어요. 하지만 실제 웹 페이지를 쓰는 사람은 콘솔을 보지 않아요. 장바구니에 담으면 합계 숫자가 바뀌고, 할 일을 끝내면 줄이 그어지고, 새 메시지가 오면 목록에 한 줄이 늘어나요. 모두 **화면이 바뀌는** 일이에요.

HTML 과정에서 브라우저가 HTML을 읽어 **DOM 트리**를 만들고, 그 트리를 보고 화면을 그린다고 배웠어요. JavaScript는 이 트리를 직접 다룰 수 있어요. 트리에서 요소를 찾고, 글자를 바꾸고, 클래스를 넣고 빼고, 새 요소를 만들어 붙이면 브라우저가 바뀐 트리를 다시 그려요.

이 단원에서는 화면을 다루는 네 가지 기본기를 배워요. 요소 **찾기**(`querySelector`), 글자 **바꾸기**(`textContent`), 모양 **바꾸기**(`classList`, `style`), 그리고 요소 **만들어 붙이기**(`createElement`, `append`)예요.
</Section>

<Section kind="principle">
### document는 DOM 트리 전체예요

브라우저는 페이지마다 `document`라는 값을 미리 만들어 둬요. `document`는 그 페이지의 DOM 트리 전체를 가리켜요. 우리가 할 일은 `document`에서 원하는 요소를 찾아, 그 요소의 글자나 모양을 바꾸는 것이에요.

```html
<h1 id="title">안녕</h1>
<script>
  document.querySelector("#title").textContent = "반가워요";
</script>
```

이 코드가 바꾸는 것은 컴퓨터에 저장된 HTML **파일이 아니라**, 브라우저가 파일을 읽어 만든 **트리**예요. 그래서 화면은 바로 `반가워요`로 바뀌지만, 페이지를 새로 고침하면 파일을 다시 읽어 `안녕`으로 돌아가요.

### querySelector로 요소 하나를 찾아요

`document.querySelector(선택자)`는 **CSS 선택자**에 맞는 요소를 찾아 돌려줘요. 선택자는 CSS 과정에서 배운 것과 똑같아요.

| 선택자 | 찾는 요소 |
|---|---|
| `"#price"` | id가 `price`인 요소 |
| `".notice"` | 클래스가 `notice`인 요소 |
| `"li"` | `li` 태그 |
| `"#menu li"` | `#menu` 안에 있는 `li` |

규칙이 두 가지 있어요.

- 맞는 요소가 여러 개면 **문서에서 가장 먼저 나오는 하나**만 돌려줘요.
- 맞는 요소가 없으면 오류 대신 **`null`** 을 돌려줘요(모듈 2에서 배운 "값이 없음"이에요).

찾은 요소는 변수에 담아 두고 여러 번 쓰는 경우가 많아요.

```js
const price = document.querySelector("#price");
```

### querySelectorAll로 모두 찾아요

맞는 요소를 **모두** 얻으려면 `document.querySelectorAll(선택자)`를 써요. 결과는 요소들의 목록이에요. 문자열처럼 `length`로 개수를 알고, `[0]`, `[1]`처럼 인덱스로 하나씩 꺼내요. 그래서 모듈 5의 `for` 반복과 함께 써요.

```js
const items = document.querySelectorAll(".item");
for (let i = 0; i < items.length; i++) {
  console.log(items[i].textContent);
}
```

모듈 8에서 배운 `for...of`로 `for (const item of items)`처럼 써도 돼요.

### 스크립트는 위에서부터 읽힌 만큼만 봐요

브라우저는 HTML을 **위에서부터** 읽으며 트리를 만들다가, `<script>`를 만나면 **그 자리에서 바로** 실행해요. 그래서 스크립트가 실행되는 순간에는 스크립트보다 위에 있는 요소만 트리에 있어요.

- `head` 안이나 요소보다 위에 있는 스크립트에서 아래쪽 요소를 찾으면 `null`이 나와요.
- 입문 단계에서는 `<script>`를 **`body`의 맨 끝**(`</body>` 바로 앞)에 두는 것이 가장 간단하고 안전해요.

### textContent로 글자를 읽고 바꿔요

`요소.textContent`는 요소 안의 글자를 문자열로 읽어요. 여기에 문자열을 대입하면 요소 안의 내용 **전체**가 그 글자로 바뀌어요. 변수에 다시 대입하는 것처럼, 원래 내용은 사라지고 덧붙지 않아요.

```js
const status = document.querySelector("#status");
console.log(status.textContent); // 지금 글자를 읽기
status.textContent = "배송 중";   // 글자를 바꾸기
```

`textContent`는 이름 그대로 **글자만** 다뤄요. `"<b>중요</b>"`를 넣으면 굵은 글씨가 아니라 꺾쇠까지 그대로 글자로 보여요. 그리고 `textContent`는 숫자를 넣어도 읽을 때는 항상 문자열이에요.

<Callout kind="note" title="innerHTML은요?">
다른 자료에서 문자열을 태그로 해석해 넣는 `innerHTML`을 보게 될 거예요. 사용자가 입력한 글자를 `innerHTML`에 넣으면 그 속의 태그가 진짜 요소가 되고, 누군가 심어 둔 코드가 실행될 수도 있어서 위험해요. 이 과정에서는 글자는 `textContent`로 넣고, 요소가 필요하면 아래에서 배울 `createElement`로 만들어요. `innerHTML`의 위험은 브라우저 JavaScript 과정의 보안 단원에서 자세히 다뤄요.
</Callout>

### classList와 style로 모양을 바꿔요

모양을 바꾸는 방법은 두 가지예요.

**클래스 넣고 빼기**가 기본이에요. CSS에 규칙을 미리 써 두고, JavaScript는 클래스만 넣고 빼요.

| 코드 | 하는 일 |
|---|---|
| `el.classList.add("done")` | `done` 클래스를 넣어요 |
| `el.classList.remove("done")` | `done` 클래스를 빼요 |
| `el.classList.toggle("done")` | 없으면 넣고, 있으면 빼요 |
| `el.classList.contains("done")` | 있으면 `true`, 없으면 `false` |

`classList`에는 선택자가 아니라 클래스 **이름**을 써요. CSS에서는 `.done`이라고 쓰지만, 점은 "클래스"를 뜻하는 선택자 기호일 뿐 이름이 아니에요.

**style로 직접 바꾸기**도 할 수 있어요. `요소.style.속성 = "값"`으로 그 요소에만 스타일을 줘요. 속성 이름은 CSS 이름에서 하이픈을 빼고 다음 글자를 대문자로 써요(낙타 표기).

<CompareTable columns={["CSS", "JavaScript의 style"]}>
<Row label="글자 크기">`font-size: 20px;` | `el.style.fontSize = "20px";`</Row>
<Row label="배경색">`background-color: yellow;` | `el.style.backgroundColor = "yellow";`</Row>
<Row label="색">`color: red;` | `el.style.color = "red";`</Row>
</CompareTable>

색이나 크기 같은 상태 표시는 클래스로 하는 편이 좋아요. 스타일이 CSS 한곳에 모여 있어서 고치기 쉽거든요.

### 새 요소는 만들고 나서 붙여요

목록에 항목을 하나 더하려면 두 단계가 필요해요.

1. `document.createElement("li")`로 새 요소를 **만들어요**. 이 요소는 아직 트리의 어디에도 붙지 않았어요.
1. `부모.append(요소)`로 부모 요소의 맨 끝에 **붙여요**. 이때 비로소 화면에 나타나요.

```js
const list = document.querySelector("#list");
const item = document.createElement("li");
item.textContent = "우유 사기";
list.append(item);
```

반대로 부모 요소의 `textContent`에 `""`를 대입하면 안의 내용(자식 요소까지)이 모두 사라져요. 목록을 처음부터 다시 그릴 때 써요.
</Section>

<Section kind="examples">
두 번째 예제는 맞는 요소를 모두 찾아 바꾸는 코드예요. 가격 세 개 모두에 `원`을 붙여요.

<RunnableExample id="query-all" lang="web" concepts={["js.dom.query-selector", "js.loops.for"]}>
```html
<ul>
  <li>김밥 <span class="price">4500</span></li>
  <li>라면 <span class="price">5000</span></li>
  <li>떡볶이 <span class="price">3000</span></li>
</ul>
<script>
  const prices = document.querySelectorAll(".price");
  console.log("가격 " + prices.length + "개");
  for (let i = 0; i < prices.length; i++) {
    prices[i].textContent = prices[i].textContent + "원";
  }
</script>
```
</RunnableExample>
</Section>

<Section kind="walkthrough">
- `querySelectorAll(".price")`는 맞는 요소 세 개를 담은 목록이에요. 콘솔에 `가격 3개`가 나와요.
- 반복 변수 `i`가 0, 1, 2를 거치며 `prices[i]`의 글자 뒤에 `원`을 붙여요. `prices[i].textContent`를 읽어 이어 붙인 문자열을 다시 대입했어요.
- 이 코드를 `querySelector`로 쓰면 김밥 가격 하나만 바뀌어요.

이번에는 직접 써 보세요. 찾은 요소마다 글자 앞에 순서 번호를 붙이는 코드예요.

</Section>

<Section kind="pitfalls">
<Pitfall misconception="js.mc.script-before-element">
<Wrong>스크립트가 `head`에 있어도 `querySelector`로 `body`의 요소를 찾을 수 있다.</Wrong>
<Actual>세 번째 예제에서 `querySelector("#greeting")`은 `null`이었고, 다음 줄에서 `TypeError`가 났어요. 스크립트가 실행될 때 `h1`은 아직 읽히지 않았어요.</Actual>
<Right>브라우저는 문서를 위에서부터 읽으며 스크립트를 만나는 즉시 실행해요. 스크립트는 `</body>` 바로 앞에 둬요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.queryselector-returns-all">
<Wrong>`querySelector(".price")`는 가격 요소를 모두 찾아 주므로, 결과의 글자를 바꾸면 모든 가격이 바뀐다.</Wrong>
<Actual>첫 번째 예제에서 `.menu`는 두 개였지만 `김밥` 하나만 나왔어요. `querySelector`는 첫 번째 요소 하나만 돌려줘요.</Actual>
<Right>모두 바꾸려면 `querySelectorAll`로 목록을 얻고 반복으로 하나씩 바꿔요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.selector-missing-prefix">
<Wrong>id가 `price`인 요소는 `querySelector("price")`로 찾는다.</Wrong>
<Actual>`"price"`는 `<price>` 태그를 찾는 선택자라서 결과가 `null`이에요.</Actual>
<Right>괄호 안은 CSS 선택자예요. id는 `"#price"`, 클래스는 `".price"`처럼 기호를 붙여요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.textcontent-appends">
<Wrong>`textContent`에 두 번 대입하면 두 글자가 이어서 보인다.</Wrong>
<Actual>대입할 때마다 요소 안의 내용 전체가 바뀌어서, 마지막에 대입한 글자만 남아요.</Actual>
<Right>덧붙이려면 두 번째 예제처럼 `el.textContent = el.textContent + "원"`으로 원래 글자를 읽어 이어 붙여요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.textcontent-parses-html">
<Wrong>`el.textContent = "<b>중요</b>"`라고 쓰면 굵은 글씨가 나온다.</Wrong>
<Actual>화면에 꺾쇠까지 `<b>중요</b>`라는 글자가 그대로 보이고, `b` 요소는 생기지 않아요.</Actual>
<Right>`textContent`는 글자만 다뤄요. 새 요소가 필요하면 `createElement`로 만들어 붙여요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.classlist-dot-prefix">
<Wrong>CSS에서 `.done`으로 쓰니까 `classList.add(".done")`처럼 점을 붙인다.</Wrong>
<Actual>오류 없이 이름이 `.done`인 클래스가 들어가요. CSS의 `.done` 규칙은 이름이 `done`인 클래스를 찾으므로 적용되지 않아요.</Actual>
<Right>`classList`에는 `"done"`처럼 이름만 써요. 점은 선택자(`querySelector`, CSS)에서만 붙여요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.style-hyphen-name">
<Wrong>CSS처럼 `el.style.background-color = "yellow"`라고 쓴다.</Wrong>
<Actual>JavaScript에서 `-`는 빼기라서 `el.style.background - color`로 읽혀요. 대입할 수 없는 자리라 실행 전에 `SyntaxError`가 나요. `fontsize`처럼 대소문자만 틀리면 오류 없이 아무 일도 일어나지 않아요.</Actual>
<Right>하이픈을 빼고 다음 글자를 대문자로 써요. `backgroundColor`, `fontSize`처럼요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.created-element-auto-shown">
<Wrong>`createElement("li")`로 만들고 글자를 넣으면 목록에 나타난다.</Wrong>
<Actual>다섯 번째 예제에서 글자를 넣은 뒤에도 목록의 항목은 1개였어요. 만든 요소는 트리에 붙지 않은 상태예요.</Actual>
<Right>`부모.append(요소)`로 트리에 붙여야 화면에 나타나요. "만들기 → 준비하기 → 붙이기" 순서를 기억해요.</Right>
</Pitfall>
</Section>

<Section kind="in-practice">
쇼핑몰 장바구니 화면에서는 상품을 담을 때마다 상품 목록에 한 줄이 늘고, 담긴 상품이 몇 개인지 아이콘 위의 숫자가 바뀌어요. 이 단원에서 배운 것만으로 그 뼈대를 만들 수 있어요.

```js
const cart = document.querySelector("#cart");
const badge = document.querySelector("#cart-badge");

const item = document.createElement("li");
item.textContent = "무선 마우스";
item.classList.add("cart-item");
cart.append(item);

const count = cart.querySelectorAll(".cart-item").length;
badge.textContent = count;
badge.classList.toggle("empty", count === 0);
```

- 새 상품은 `createElement`로 만들어 `append`해요.
- 개수는 화면에서 다시 세어 배지에 써요. 따로 숫자 변수를 두지 않아도 화면과 숫자가 어긋나지 않아요.
- 마지막 줄의 `toggle`에 두 번째 인수로 `true`·`false`를 주면, 그 값에 따라 넣기만 하거나 빼기만 해요. 빈 장바구니일 때만 `empty` 클래스가 붙어요.

연습 문제에서 상품이 늘 때마다 합계를 다시 계산하는 장바구니와, 메뉴판을 새로 그리는 함수를 직접 만들어 봐요. 버튼을 누를 때 코드가 실행되게 하는 방법은 다음 단원에서 배워요. 그 전까지는 연습 문제의 시작 코드에 미리 연결해 두었어요.
</Section>

<Section kind="summary">
- `document`는 브라우저가 HTML로 만든 DOM 트리 전체예요. JavaScript는 파일이 아니라 이 트리를 바꾸고, 브라우저가 바뀐 트리를 다시 그려요.
- `querySelector(선택자)`는 CSS 선택자에 맞는 첫 번째 요소 하나를, 없으면 `null`을 돌려줘요. 모두 얻으려면 `querySelectorAll`을 쓰고 반복으로 하나씩 다뤄요.
- 스크립트는 위에서부터 읽힌 만큼의 트리만 볼 수 있어요. `<script>`는 `</body>` 바로 앞에 둬요.
- `textContent`에 대입하면 요소 안의 내용 전체가 그 글자로 바뀌어요. 태그도 글자로 보여요.
- `classList.add`·`remove`·`toggle`·`contains`에는 점 없이 클래스 이름을 쓰고, `style`의 속성 이름은 `fontSize`처럼 낙타 표기로 써요.
- `createElement`로 만든 요소는 `append`로 붙여야 화면에 나타나요.
</Section>
