<Section kind="objectives">
- 바깥 반복이 한 번 돌 때마다 안쪽 반복이 처음부터 끝까지 다시 돈다는 것을 알고, 안쪽 본문의 실행 횟수와 출력 순서를 예측할 수 있어요.
- 바깥 반복 변수로 안쪽 반복의 범위를 바꿔 삼각형처럼 줄마다 길이가 다른 모양을 만들 수 있어요.
- 중첩 반복으로 구구단표·좌석표 같은 표를 출력하는 프로그램을 작성할 수 있어요.
- 안쪽 반복의 `break`가 안쪽 반복만 끝낸다는 것을 알고, 바깥 반복까지 멈추는 코드를 작성할 수 있어요.
</Section>

<Section kind="intro">
영화관 좌석 안내판을 만든다고 해 볼게요. 좌석은 1열부터 3열까지 있고, 열마다 1번부터 4번까지 자리가 있어요. "1열 1번, 1열 2번, …, 3열 4번"을 모두 출력하려면 어떻게 해야 할까요?

한 열의 자리 네 개는 `for` 하나로 출력할 수 있어요. 그런데 이 일을 **열마다** 다시 해야 해요. "열마다 반복하기" 안에 "자리마다 반복하기"가 들어 있는 셈이에요.

이렇게 반복 안에 반복을 넣는 것을 **중첩 반복**이라고 해요. 표, 달력, 바둑판, 구구단 전체처럼 **가로와 세로가 있는 것**을 다룰 때 자연스럽게 쓰게 돼요.
</Section>

<Section kind="principle">
### 중첩 반복의 모양

```js
for (let row = 1; row <= 3; row++) {      // 바깥 반복: 열
  for (let seat = 1; seat <= 4; seat++) { // 안쪽 반복: 자리
    console.log(row + "열 " + seat + "번");
  }
}
```

모듈 4에서 블록 안에 다른 `if`를 넣을 수 있었던 것처럼, 반복의 본문(블록)에도 어떤 문장이든 넣을 수 있어요. 다른 반복도요. 이때 바깥에 있는 반복을 **바깥 반복**, 안에 있는 반복을 **안쪽 반복**이라고 불러요.

### 안쪽 반복은 바깥 회차마다 처음부터 다시 돌아요

핵심은 하나예요. **안쪽 `for` 문 전체가 바깥 반복의 본문**이라는 것이에요. 본문은 회차마다 처음부터 실행되니까, 바깥 회차마다 안쪽 `for`도 초기화(`let seat = 1`)부터 다시 시작해서 끝까지 돌아요.

```text
row = 1 → seat 1, 2, 3, 4 (안쪽 반복 한 바퀴)
row = 2 → seat 1, 2, 3, 4 (다시 처음부터)
row = 3 → seat 1, 2, 3, 4
```

시계로 생각하면 쉬워요. 분침(안쪽 반복)이 한 바퀴를 다 돌아야 시침(바깥 반복)이 한 칸 움직이고, 시침이 움직이면 분침은 다시 0분부터 돌아요.

### 실행 횟수는 곱이에요

바깥 반복이 3번, 안쪽 반복이 4번이면 안쪽 본문은 **3 × 4 = 12번** 실행돼요. 바깥 회차 하나마다 안쪽 반복이 4번씩 통째로 돌기 때문이에요. 3 + 4 = 7번이 아니에요.

| 바깥 횟수 | 안쪽 횟수 | 안쪽 본문 실행 횟수 |
|---|---|---|
| 3 | 4 | 12 |
| 8 (구구단 2단부터 9단까지) | 9 (곱하는 수 1부터 9까지) | 72 |
| 10 | 10 | 100 |

반복을 겹칠수록 실행 횟수가 빠르게 늘어나요. 실행이 느려지면 중첩 반복의 횟수부터 확인해 보세요.

### 안쪽 범위를 바깥 반복 변수로 정할 수 있어요

안쪽 반복의 조건에 바깥 반복 변수를 쓰면, 줄마다 안쪽 반복의 횟수가 달라져요. 삼각형 모양이 대표적이에요.

```js
for (let line = 1; line <= 4; line++) {
  let stars = "";
  for (let k = 1; k <= line; k++) {
    stars += "*";
  }
  console.log(stars);
}
```

`line`이 1이면 별 1개, 2면 2개, …, 4면 4개를 이어 붙여요. `let stars = "";`는 바깥 반복의 본문에 있어서 줄마다 빈 문자열에서 다시 시작해요. 여기서는 "줄마다 새로 모으기"가 바라는 동작이에요.

### break는 가장 가까운 반복 하나만 끝내요

앞 단원에서 본 것처럼 안쪽 반복 안의 `break`는 **안쪽 반복만** 끝내요. 실행은 바깥 반복 본문의 안쪽 `for` 다음 줄로 이어지고, 바깥 반복은 다음 회차로 넘어가요.

바깥 반복까지 멈추려면, 찾았는지를 기억하는 변수를 두고 바깥 반복에서도 검사해요.

```js
let found = false;
for (let a = 1; a <= 9; a++) {
  for (let b = 1; b <= 9; b++) {
    if (a * b === 12) {
      console.log(a + " x " + b + " = 12");
      found = true;
      break;        // 안쪽 반복 끝
    }
  }
  if (found) {
    break;          // 바깥 반복도 끝
  }
}
```

이렇게 "찾았다"는 표시로 쓰는 불리언 변수를 **플래그**라고 불러요. 깃발을 올려 두고 바깥에서 그 깃발을 확인하는 셈이에요.
</Section>

첫 번째 예제는 가장 단순한 중첩 반복이에요. 몇 줄이, 어떤 순서로 출력될까요?

<RunnableExample id="pairs" lang="js" predict predictKind="console" concepts={["js.loops.nested"]}>
```js
for (let row = 1; row <= 2; row++) {
  for (let seat = 1; seat <= 3; seat++) {
    console.log(row + "열 " + seat + "번");
  }
  console.log("--- " + row + "열 끝");
}
```
</RunnableExample>

<Section kind="walkthrough">
```text
1열 1번
1열 2번
1열 3번
--- 1열 끝
2열 1번
2열 2번
2열 3번
--- 2열 끝
```

| 바깥 회차 | `row` | 안쪽 반복에서 `seat` | 안쪽 반복이 끝난 뒤 |
|---|---|---|---|
| 1 | 1 | 1, 2, 3 | `--- 1열 끝` |
| 2 | 2 | 1, 2, 3 (다시 1부터) | `--- 2열 끝` |

- 3번 줄(안쪽 본문)은 2 × 3 = 6번 실행됐어요.
- 5번 줄은 안쪽 반복 **바깥**, 바깥 반복 **안**에 있어서 열마다 한 번씩, 모두 2번 실행돼요.
- 2열이 시작될 때 안쪽 `for`가 `let seat = 1`부터 다시 실행되어 `seat`가 1로 돌아왔어요.
</Section>

<Section kind="examples">
두 번째 예제는 중첩 반복과 누적 패턴으로 구구단 일부를 표처럼 한 줄씩 출력해요. 실행해 보고, 바깥 반복의 `4`를 `9`로 바꿔 다시 실행해 보세요.

<RunnableExample id="times-grid" lang="js" concepts={["js.loops.nested"]}>
```js
for (let dan = 2; dan <= 4; dan++) {
  let line = dan + "단:";
  for (let i = 1; i <= 5; i++) {
    line += " " + dan * i;
  }
  console.log(line);
}
```
</RunnableExample>
</Section>

<Section kind="walkthrough">
```text
2단: 2 4 6 8 10
3단: 3 6 9 12 15
4단: 4 8 12 16 20
```

- 바깥 반복이 한 줄(한 단)을, 안쪽 반복이 그 줄의 칸(곱)을 맡아요.
- `line`은 바깥 본문에서 만들어서 단마다 `"2단:"`, `"3단:"`처럼 새로 시작해요. 안쪽 반복이 그 줄에 곱을 하나씩 이어 붙이고, 줄이 완성되면 바깥 본문에서 한 번 출력해요.
- 가로(칸)는 안쪽 반복, 세로(줄)는 바깥 반복이라고 기억하면 표를 만들 때 편해요.
</Section>

<Section kind="examples">
세 번째 예제는 안쪽 반복의 범위가 바깥 반복 변수에 따라 달라지는 코드예요. 어떤 모양이 출력될까요?

<RunnableExample id="number-triangle" lang="js" predict predictKind="console" concepts={["js.loops.nested"]}>
```js
for (let line = 1; line <= 4; line++) {
  let text = "";
  for (let k = 1; k <= line; k++) {
    text += k;
  }
  console.log(text);
}
```
</RunnableExample>
</Section>

<Section kind="walkthrough">
```text
1
12
123
1234
```

| `line` | 안쪽 반복에서 `k` | `text` |
|---|---|---|
| 1 | 1 | `"1"` |
| 2 | 1, 2 | `"12"` |
| 3 | 1, 2, 3 | `"123"` |
| 4 | 1, 2, 3, 4 | `"1234"` |

- 안쪽 조건이 `k <= line`이라서 줄마다 안쪽 반복의 횟수가 1, 2, 3, 4로 늘어나요.
- `text`는 빈 문자열 `""`에서 시작해서 `text += k`가 숫자를 글자로 이어 붙여요(모듈 3의 문자열 연결). 그래서 `1 + 2`가 아니라 `"12"`가 돼요.
- 안쪽 본문의 실행 횟수는 1 + 2 + 3 + 4 = 10번이에요. 안쪽 범위가 줄마다 다르면 단순한 곱이 아니라 줄별 횟수의 합이에요.

<Section kind="examples">
네 번째 예제는 중첩 반복 안의 `break`예요. 플래그 없이 안쪽 반복에서만 `break`하면 어떻게 되는지 예측해 보세요.

<RunnableExample id="inner-break" lang="js" predict predictKind="console" concepts={["js.loops.nested", "js.loops.break"]}>
```js
for (let a = 1; a <= 3; a++) {
  for (let b = 1; b <= 3; b++) {
    if (b === 2) {
      break;
    }
    console.log(a + "-" + b);
  }
}
console.log("끝");
```
</RunnableExample>
</Section>

<Section kind="walkthrough">
```text
1-1
2-1
3-1
끝
```

- 바깥 회차마다 안쪽 반복은 `b`가 1일 때 출력하고, 2가 되면 `break`로 끝나요.
- 안쪽 반복이 끝나도 **바깥 반복은 계속**돼요. 그래서 `a`가 2, 3일 때도 안쪽 반복이 다시 시작되어 `2-1`, `3-1`이 나와요.
- 바깥 반복까지 한 번에 멈추고 싶다면 원리에서 본 것처럼 플래그(`found`)를 두고 바깥 반복에서도 `break`해요.
</Section>

<Section kind="pitfalls">
<Pitfall misconception="js.mc.inner-var-not-reset">
<Wrong>안쪽 `for`의 `seat`가 첫 바깥 회차에서 3까지 간 뒤로는 그 값에 머물러 있어서, 다음 바깥 회차에서는 안쪽 반복이 실행되지 않는다.</Wrong>
<Actual>

첫 번째 예제에서 2열에도 `1번`부터 `3번`까지 모두 나왔어요. 안쪽 `for` 문 전체가 바깥 본문이라 바깥 회차마다 `let seat = 1`부터 다시 실행돼요.

다만 안쪽 반복의 변수를 바깥 반복보다 **먼저** 만들어 두면 이야기가 달라요. 아래 코드는 `seat`를 다시 1로 만드는 줄이 없어서, 2열부터는 안쪽 `while`이 한 번도 돌지 않아요.

```js
let seat = 1;
for (let row = 1; row <= 2; row++) {
  while (seat <= 3) {
    console.log(row + "열 " + seat + "번");
    seat++;
  }
}
// 1열 1번, 1열 2번, 1열 3번 (2열은 나오지 않음)
```
</Actual>
<Right>안쪽 반복의 변수는 안쪽 `for`의 초기화에서 만들어요. 그러면 바깥 회차마다 자동으로 처음 값부터 다시 시작해요. `while`을 쓴다면 바깥 본문 안에서 `let seat = 1;`로 다시 시작값을 줘요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.nested-count-additive">
<Wrong>바깥 3번, 안쪽 4번 도는 중첩 반복에서 안쪽 본문은 3 + 4 = 7번 실행된다.</Wrong>
<Actual>바깥 회차마다 안쪽 반복이 4번씩 통째로 돌아요. 그래서 4 + 4 + 4 = 3 × 4 = 12번이에요.</Actual>
<Right>안쪽 본문의 실행 횟수는 (바깥 횟수) × (안쪽 횟수)예요. 안쪽 범위가 줄마다 다르면 줄별 안쪽 횟수를 모두 더해요.</Right>
</Pitfall>
</Section>

<Section kind="in-practice">
웹 페이지의 달력이나 표는 결국 "줄 × 칸"이에요. 한 달 달력의 날짜 칸을 만드는 코드를 단순하게 써 보면 이래요.

```js
let day = 1;
for (let week = 1; week <= 5; week++) {
  let line = "";
  for (let weekday = 1; weekday <= 7; weekday++) {
    if (day <= 30) {
      line += day + " ";
    }
    day++;
  }
  console.log(week + "주차: " + line);
}
```

- 바깥 반복은 주(줄), 안쪽 반복은 요일(칸)이에요. 5주 × 7일 = 35칸을 돌면서 30일까지만 채워요.
- `day`는 바깥 반복보다 먼저 만들어서 주가 바뀌어도 이어서 늘어나요. 이번에는 **다시 시작하지 않는 것**이 바라는 동작이에요. 변수를 어디서 만드느냐로 "줄마다 다시 시작"과 "계속 이어 가기"를 고를 수 있어요.

실제 화면에서는 이 줄과 칸을 HTML 표의 `<tr>`(줄)과 `<td>`(칸)로 만들어요. 화면을 만드는 방법은 모듈 10에서 배워요.
</Section>

<Section kind="summary">
- 반복의 본문에 다른 반복을 넣을 수 있어요(중첩 반복). 바깥 반복은 줄, 안쪽 반복은 칸을 맡는 경우가 많아요.
- 안쪽 `for` 문 전체가 바깥 반복의 본문이라서, 바깥 회차마다 안쪽 반복이 초기화부터 다시 시작해 끝까지 돌아요.
- 안쪽 본문의 실행 횟수는 (바깥 횟수) × (안쪽 횟수)예요.
- 안쪽 조건에 바깥 반복 변수를 쓰면 줄마다 안쪽 횟수가 달라져요(삼각형 모양).
- 변수를 바깥 본문에서 만들면 줄마다 다시 시작하고, 바깥 반복보다 먼저 만들면 계속 이어져요.
- 안쪽 반복의 `break`는 안쪽 반복만 끝내요. 바깥 반복까지 멈추려면 플래그를 두고 바깥에서도 `break`해요.
</Section>
