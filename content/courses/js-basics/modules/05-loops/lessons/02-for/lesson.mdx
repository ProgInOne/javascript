<Section kind="objectives">
- `for` 문의 초기화·조건·갱신이 실행되는 순서를 알고, 반복 횟수와 회차마다의 반복 변수 값을 예측할 수 있어요.
- 시작값과 조건을 골라 원하는 횟수만큼 반복하는 `for` 문을 작성하고, 횟수가 하나씩 어긋나는 버그를 고칠 수 있어요.
- 반복 변수를 본문의 계산에 쓰고, 반복이 끝난 뒤 반복 변수를 쓸 수 있는지와 그 값을 설명할 수 있어요.
- 누적 변수를 반복 바깥에서 시작값으로 만들고 본문에서 더해 가는 누적 패턴으로 합계·개수·문자열을 만들 수 있어요.
</Section>

<Section kind="intro">
앞 단원에서 `while`로 카운트다운을 만들었어요. 다시 보면 반복을 위한 코드가 세 군데에 흩어져 있어요.

```js
let count = 5;          // ① 시작값
while (count > 0) {     // ② 조건
  console.log(count);
  count--;              // ③ 변수 바꾸기
}
```

본문이 길어지면 ③이 화면 아래로 밀려나서, 빠뜨리거나(무한 반복) 엉뚱한 곳에 쓰기 쉬워요. 그런데 "5번 반복", "1번부터 30번까지"처럼 **횟수가 정해진 반복**은 프로그램에서 아주 흔해요. 출석부의 30명에게 차례로 인사하기, 1월부터 12월까지 매달 저축액 출력하기, 구구단 7단 출력하기가 모두 그래요.

`for` 문은 ①②③을 괄호 한 줄에 모아 써서, 반복이 어떻게 시작하고 언제 끝나는지 첫 줄만 보고 알 수 있게 해 줘요. 이 단원에서는 `for` 문과 함께, 반복하며 합계를 모으는 **누적 패턴**을 배워요. 반복문으로 할 수 있는 일의 대부분이 이 두 가지의 조합이에요.
</Section>

<Section kind="principle">
### for의 모양

```js
for (초기화; 조건; 갱신) {
  // 본문
}
```

괄호 안은 세미콜론 `;` 두 개로 세 부분을 나눠요. 카운트다운을 `for`로 쓰면 이래요.

```js
for (let count = 5; count > 0; count--) {
  console.log(count);
}
```

| 부분 | 예 | 하는 일 | 언제 |
|---|---|---|---|
| 초기화 | `let count = 5` | 반복 변수를 만들고 시작값을 넣어요 | 반복을 시작할 때 **딱 한 번** |
| 조건 | `count > 0` | 참이면 본문을 실행하고, 거짓이면 반복을 끝내요 | **회차마다 본문 전에** |
| 갱신 | `count--` | 반복 변수를 바꿔요 | **회차마다 본문 뒤에** |

### 실행 순서: 초기화 → (조건 → 본문 → 갱신) 반복

`for`는 이 순서로 실행해요.

1. **초기화**를 한 번 실행해요.
1. **조건**을 검사해요. 거짓이면 반복을 끝내고 반복 다음 문장으로 가요.
1. 참이면 **본문**을 실행해요.
1. **갱신**을 실행하고 2번으로 돌아가요.

```text
초기화 (한 번)
  ↓
조건 ── 거짓 → 반복 다음 문장
  │ 참
  ↓
본문
  ↓
갱신 → 다시 조건으로
```

갱신은 괄호 안에서 조건 옆에 적혀 있지만, 실제로는 **본문을 실행한 뒤에** 실행돼요. 그래서 `for (let i = 0; ...; i++)`의 첫 회차에서 `i`는 1이 아니라 0이에요.

### 두 가지 관점: for는 while을 한 줄로 모은 것이에요

**while로 펼쳐 보기.** 아래 두 코드는 똑같이 동작해요. `for`의 세 부분이 `while`의 어디로 가는지 비교해 보세요.

<CompareTable columns={["for", "같은 일을 하는 while"]}>
<Row label="초기화">`for (let i = 0; …; …)` | 반복 앞의 `let i = 0;`</Row>
<Row label="조건">`for (…; i < 3; …)` | `while (i < 3)`</Row>
<Row label="갱신">`for (…; …; i++)` | 본문 맨 끝의 `i++;`</Row>
</CompareTable>

그래서 `while`에서 배운 규칙이 그대로 통해요. 조건은 회차 전에만 검사하고, 처음부터 거짓이면 본문은 한 번도 실행되지 않아요.

**값 추적 관점.** 반복을 읽을 때는 회차마다 반복 변수의 값을 표로 적어 보는 것이 가장 확실해요. `for (let i = 0; i < 3; i++)`를 추적하면 이래요.

| 단계 | `i` | 일어나는 일 |
|---|---|---|
| 초기화 | 0 | `i`를 0으로 만들어요 |
| 조건 | 0 | `0 < 3` 참 → 본문 실행 (1회차) |
| 갱신 | 1 | |
| 조건 | 1 | `1 < 3` 참 → 본문 실행 (2회차) |
| 갱신 | 2 | |
| 조건 | 2 | `2 < 3` 참 → 본문 실행 (3회차) |
| 갱신 | 3 | |
| 조건 | 3 | `3 < 3` 거짓 → 반복 끝 |

본문에서 본 `i`는 0, 1, 2예요. 3은 조건을 거짓으로 만들어 반복을 끝낸 값이에요.

### 반복 횟수 세기

반복 횟수는 **시작값과 조건이 함께** 정해요. 가장 많이 쓰는 두 모양을 기억해 두면 편해요.

| 모양 | `i`가 거치는 값 | 횟수 |
|---|---|---|
| `for (let i = 0; i < 5; i++)` | 0, 1, 2, 3, 4 | 5번 |
| `for (let i = 1; i <= 5; i++)` | 1, 2, 3, 4, 5 | 5번 |
| `for (let i = 0; i <= 5; i++)` | 0, 1, 2, 3, 4, 5 | **6번** |

헷갈리면 **첫 값과 마지막 값**을 직접 적어 보세요. 마지막 값은 조건이 아직 참인 가장 큰 값이에요. 반복 횟수가 하나씩 어긋나는 실수는 아주 흔해서 "off-by-one 오류"라는 이름이 따로 있을 정도예요.

갱신은 `i++`만 있는 게 아니에요. `i += 2`(두 칸씩), `i--`(거꾸로)처럼 필요한 대로 써요. 다만 갱신이 조건을 거짓으로 만드는 쪽이어야 반복이 끝나요.

### 반복 변수

`i`처럼 회차마다 값이 바뀌는 변수를 **반복 변수**라고 해요. 반복 변수는 횟수를 세는 데만 쓰는 게 아니라, 본문에서 **계산에 쓸 수 있는 값**이에요. 구구단 7단은 `i`가 1부터 9까지 바뀌는 것을 이용해요.

```js
for (let i = 1; i <= 9; i++) {
  console.log("7 x " + i + " = " + 7 * i);
}
```

반복 변수에 대해 두 가지를 더 알아 둬요.

- **`for (let i …)`의 `i`는 그 반복 안에서만 쓸 수 있어요.** 앞 모듈에서 블록 안에서 만든 변수는 블록 밖에서 쓸 수 없다고 했죠. `for` 괄호에서 만든 변수도 같아서, 반복이 끝난 뒤 `i`를 쓰면 `ReferenceError: i is not defined`가 나요.
- **반복이 끝난 뒤의 값은 "조건을 거짓으로 만든 값"이에요.** 반복 바깥에서 만든 변수로 세면 반복 뒤에도 쓸 수 있는데, 이때 값은 마지막 회차의 값보다 하나 더 간 값이에요. `let n = 0; while (n < 5) { n++; }`이 끝나면 `n`은 4가 아니라 5예요.

반복 변수는 `let`으로 만들어요. `const`로 만들면 갱신 `i++`가 상수를 바꾸려고 해서 첫 회차가 끝나자마자 `TypeError: Assignment to constant variable.`이 나요.

### 누적 패턴: 반복하며 값을 모아요

"1부터 5까지 더하기", "장바구니 금액 합계", "짝수의 개수 세기"처럼 반복하며 값을 **모으는** 일에는 정해진 모양이 있어요. 이것을 **누적 패턴**이라고 해요.

```js
let total = 0;                     // ① 반복 전에, 반복 바깥에서 시작값으로
for (let i = 1; i <= 5; i++) {
  total += i;                      // ② 본문에서 조금씩 더하기
}
console.log(total);                // ③ 반복이 끝난 뒤 결과 쓰기
```

`total`처럼 값을 모으는 변수를 **누적 변수**라고 해요. 세 가지가 중요해요.

| 할 일 | 이유 |
|---|---|
| 시작값을 정해요. 합계·개수는 `0`, 이어 붙일 글자는 `""` | 시작값이 없으면 `undefined`라서 `undefined + 1`이 `NaN`이 돼요 |
| 반복 **바깥(앞)**에서 만들어요 | 본문 안에서 만들면 회차마다 다시 0이 되고, 반복 뒤에는 쓸 수도 없어요 |
| `=`가 아니라 `+=`로 더해요 | `total = i`는 원래 값을 버리고 덮어써요 |

같은 모양으로 여러 가지를 모을 수 있어요.

| 모으는 것 | 시작값 | 본문 |
|---|---|---|
| 합계 | `let sum = 0;` | `sum += 값;` |
| 개수 | `let count = 0;` | 조건이 맞을 때 `count++;` |
| 이어 붙인 글자 | `let line = "";` | `line += "★";` |
</Section>

<Section kind="pitfalls">
<Pitfall misconception="js.mc.for-off-by-one">
<Wrong>`for (let i = 0; i <= 5; i++)`는 5번 반복한다. 5까지 세니까.</Wrong>
<Actual>`i`가 0, 1, 2, 3, 4, 5를 거쳐 **6번** 반복해요. 0부터 시작하면서 `<=`로 끝을 포함했기 때문이에요.</Actual>
<Right>첫 값과 마지막 값을 직접 적어 봐요. 5번이 필요하면 `i = 0; i < 5` 또는 `i = 1; i <= 5`처럼 시작값과 비교 연산자를 짝지어 써요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.for-update-before-body">
<Wrong>`for (let i = 0; i < 3; i++)`에서 `i++`가 먼저 실행되니까 첫 회차의 `i`는 1이다.</Wrong>
<Actual>두 번째 예제의 첫 줄은 `i = 0`이었어요. 갱신은 본문을 실행한 **뒤에** 실행돼요.</Actual>
<Right>순서는 초기화 → 조건 → 본문 → 갱신 → 조건 → …이에요. 괄호 안에 적힌 위치가 아니라 이 순서로 읽어요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.for-init-every-time">
<Wrong>`let i = 0`이 회차마다 다시 실행되어 `i`가 매번 0으로 돌아간다.</Wrong>
<Actual>그랬다면 `i`가 영원히 0이라 반복이 끝나지 않았을 거예요. 초기화는 반복을 시작할 때 딱 한 번만 실행돼요.</Actual>
<Right>초기화는 한 번, 조건·본문·갱신은 회차마다예요. `while`로 펼치면 초기화는 반복 **앞**의 한 줄이에요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.loop-var-outside-for">
<Wrong>`for (let i = 1; i <= 3; i++) { … }` 다음 줄에서 `console.log(i)`를 쓰면 마지막 값이 나온다.</Wrong>
<Actual>

`for` 괄호에서 `let`으로 만든 `i`는 그 반복 안에서만 있어요. 반복 뒤에서 쓰면 `ReferenceError: i is not defined`가 나요.

```js
for (let i = 1; i <= 3; i++) {
  console.log(i);
}
console.log("마지막: " + i); // ReferenceError
```
</Actual>
<Right>반복이 끝난 뒤에도 필요한 값은 반복 **바깥(위)**에서 만든 변수에 담아요. 예를 들어 횟수가 필요하면 `let count = 0;`을 반복 앞에 만들고 본문에서 늘려요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.loop-var-final-value">
<Wrong>`let n = 0; while (n < 5) { n++; }`이 끝나면 `n`은 마지막 회차의 값인 4다.</Wrong>
<Actual>반복은 조건이 **거짓이 되어야** 끝나요. `n`이 5가 되어 `5 < 5`가 거짓이 될 때 끝나니, 반복 뒤의 `n`은 5예요.</Actual>
<Right>반복이 끝난 뒤의 반복 변수는 "조건을 거짓으로 만든 값"이에요. 값 추적 표의 마지막 줄(조건 거짓)을 보면 알 수 있어요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.accumulator-reset-in-loop">
<Wrong>`let total = 0;`을 반복 본문 안에 써도 합계가 쌓인다.</Wrong>
<Actual>

본문 안의 `let total = 0;`은 회차마다 다시 실행되어 `total`을 0으로 되돌려요. 아래 코드는 누적하지 못하고 회차마다 그 회차의 값만 출력해요.

```js
for (let i = 1; i <= 3; i++) {
  let total = 0;
  total += i;
  console.log(total); // 1, 2, 3 (1, 3, 6이 아님)
}
```
</Actual>
<Right>누적 변수는 반복 **앞에서 한 번만** 만들어요. 본문에는 더하는 줄만 둬요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.accumulator-overwrite">
<Wrong>반복 안에서 `total = price;`라고 쓰면 `price`가 `total`에 더해진다.</Wrong>
<Actual>`=`는 원래 값을 버리고 새 값으로 바꿔요. 반복이 끝나면 마지막 회차의 `price`만 남아요.</Actual>
<Right>더해서 쌓으려면 `total += price;`(`total = total + price;`와 같아요)를 써요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.accumulator-no-init">
<Wrong>`let total;`처럼 시작값 없이 만들어도 0부터 더해진다.</Wrong>
<Actual>시작값 없이 만든 변수는 `undefined`예요. `undefined + 1`은 `NaN`이고, `NaN`에 무엇을 더해도 `NaN`이라 결과가 `NaN`이 돼요.</Actual>
<Right>누적 변수에는 항상 시작값을 줘요. 합계·개수는 `0`, 이어 붙일 글자는 `""`예요.</Right>
</Pitfall>
</Section>

<Section kind="in-practice">
은행 앱의 "월별 저축 계획" 화면을 만든다고 해 볼게요. 매달 같은 금액을 저축할 때 달마다 누적 금액을 보여 주는 코드는 `for`와 누적 패턴의 조합이에요.

```js
const monthly = 50000;
let saved = 0;

for (let month = 1; month <= 6; month++) {
  saved += monthly;
  console.log(month + "월: " + saved + "원");
}
console.log("6개월 저축 합계: " + saved + "원");
```

- 반복 변수 `month`는 몇 월인지 보여 주는 데 쓰여요. 1월부터 시작하므로 `month = 1; month <= 6`으로 6번이에요.
- 누적 변수 `saved`는 반복 바깥에서 0으로 시작해서, 달마다 쌓인 금액을 보여 줘요. 반복이 끝난 뒤에도 그대로 쓸 수 있어요.

실제 웹 개발에서는 모듈 8에서 배울 배열과 함께 `for`를 가장 많이 써요. 장바구니 상품들의 가격을 하나씩 꺼내 합계를 내고, 게시글 목록에서 조건에 맞는 글의 개수를 세고, 여러 줄의 HTML을 문자열로 이어 붙여 화면을 만드는 일이 모두 지금 배운 "반복 + 누적"이에요.
</Section>

<Section kind="summary">
- `for (초기화; 조건; 갱신) { 본문 }`은 초기화를 한 번 실행한 뒤 조건 → 본문 → 갱신을 조건이 거짓이 될 때까지 되풀이해요.
- 갱신은 본문 **뒤에** 실행돼요. 그래서 첫 회차의 반복 변수는 초기화한 값이에요.
- 반복 횟수는 시작값과 조건이 함께 정해요. `i = 0; i < 5`와 `i = 1; i <= 5`는 5번, `i = 0; i <= 5`는 6번이에요.
- 반복 변수는 본문의 계산에 쓸 수 있어요. `for (let i …)`의 `i`는 반복 안에서만 쓸 수 있고, 반복 바깥 변수로 세면 끝난 뒤의 값은 조건을 거짓으로 만든 값이에요.
- 누적 패턴: 누적 변수를 반복 앞에서 시작값(`0`, `""`)으로 만들고, 본문에서 `+=`로 더하고, 반복 뒤에 결과를 써요.
- 누적 변수를 본문 안에서 만들거나, `=`로 덮어쓰거나, 시작값을 빠뜨리면 합계가 틀려요.
</Section>
