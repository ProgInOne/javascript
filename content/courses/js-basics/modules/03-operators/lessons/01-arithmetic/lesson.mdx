<Section kind="objectives">
- `+ - * / **`로 계산식을 쓰고, 나눗셈이 소수까지 계산된다는 점을 고려해 결과를 예측할 수 있어요.
- 우선순위와 괄호에 따라 계산식이 어떤 순서로 계산되는지 단계별로 설명할 수 있어요.
- `%`로 나머지를 구해 짝수·홀수나 묶고 남는 개수를 계산할 수 있어요.
- `+=`, `-=` 같은 복합 대입과 `++`, `--`로 변수 값을 바꾸고, `a++`와 `++a`의 값 차이를 예측할 수 있어요.
</Section>

<Section kind="intro">
친구들과 다섯 명이서 피자를 시켰어요. 피자는 한 판에 18900원짜리 3판이고, 배달 팁은 음식값의 10%예요. 한 사람이 얼마를 내야 할까요? 계산기를 꺼내 하나씩 누르다 보면 중간에 순서를 헷갈리기 쉬워요.

프로그램은 이런 계산을 대신해 줘요. 그런데 프로그램에게 계산을 시키려면 **연산자**를 정확히 알아야 해요. 예를 들어 JavaScript에서 거듭제곱은 `^`가 아니라 `**`이고, `%`는 퍼센트가 아니라 "나머지"예요. 계산 순서도 정해진 규칙을 따르기 때문에, 규칙을 모르면 프로그램은 오류 없이 **틀린 답**을 내요. 오류 메시지조차 없으니 더 찾기 어렵죠.

이 단원에서는 숫자를 계산하는 연산자, 계산 순서, 나머지, 그리고 변수의 값을 줄여 쓰는 방법(`+=`, `++`)까지 배워요. 거의 모든 프로그램이 이 연산자들로 점수, 가격, 개수, 시간을 계산해요.
</Section>

<Section kind="principle">
### 산술 연산자: 계산해서 새 값을 만들어요

| 연산자 | 뜻 | 예 | 결과 |
|---|---|---|---|
| `+` | 더하기 | `7 + 2` | `9` |
| `-` | 빼기 | `7 - 2` | `5` |
| `*` | 곱하기 | `7 * 2` | `14` |
| `/` | 나누기 | `7 / 2` | `3.5` |
| `**` | 거듭제곱 | `2 ** 3` | `8` (2 × 2 × 2) |
| `%` | 나머지 | `7 % 2` | `1` |

두 가지를 꼭 기억해요.

- **`/`는 소수까지 계산해요.** `7 / 2`는 몫 3이 아니라 `3.5`예요. 수학 시간의 "몫과 나머지" 나눗셈이 아니에요.
- **거듭제곱은 `**`예요.** 계산기나 문서에서 쓰는 `2^3` 표기를 그대로 쓰면 `2 ^ 3`은 전혀 다른 연산(비트 연산)이 되어 `1`이 나와요. 오류도 나지 않아서 알아차리기 어려워요.

계산식(`score + 10`)은 **새 값을 만들 뿐, 변수를 바꾸지 않아요.** 변수의 값을 바꾸는 것은 지난 단원에서 배운 대입(`=`)뿐이에요.

```js
let score = 50;
console.log(score + 10);   // 60을 출력하지만
console.log(score);        // score는 여전히 50
score = score + 10;        // 대입해야 바뀌어요
console.log(score);        // 60
```

### 우선순위: 무엇을 먼저 계산할까요

계산식에 연산자가 여러 개 있으면 정해진 순서로 계산해요. 수학 시간의 순서와 거의 같아요.

| 순서 | 연산자 | 같은 순서끼리는 |
|---|---|---|
| 1 | `( )` 괄호 안 | 안쪽부터 |
| 2 | `**` | 오른쪽부터 |
| 3 | `*` `/` `%` | 왼쪽부터 |
| 4 | `+` `-` | 왼쪽부터 |

`*`와 `/`는 **같은 순서**예요. "곱셈이 먼저"가 아니라 왼쪽에 있는 것이 먼저예요.

**관점 1. 한 단계씩 줄여 가기**: 계산식을 가장 먼저 계산할 부분부터 하나씩 값으로 바꿔 써 보면 실수가 줄어요.

| 단계 | 계산식 |
|---|---|
| 시작 | `20 - 12 / 4 * 2 + 1` |
| `/`와 `*`는 같은 순서라 왼쪽의 `12 / 4`부터 | `20 - 3 * 2 + 1` |
| `3 * 2` | `20 - 6 + 1` |
| `+`와 `-`도 왼쪽부터: `20 - 6` | `14 + 1` |
| `14 + 1` | `15` |

**관점 2. 괄호를 쳐 보기**: 우선순위가 높은 연산에 보이지 않는 괄호가 쳐져 있다고 생각해요. `20 - 12 / 4 * 2 + 1`은 `(20 - ((12 / 4) * 2)) + 1`과 같아요. 내 의도와 다르게 묶이면 **직접 괄호를 써서** 순서를 정해요. 괄호는 읽는 사람에게도 의도를 알려 줘요.

### 나머지 `%`: 나누고 남는 수

`a % b`는 a를 b로 나눈 **나머지**예요. 퍼센트(백분율)와는 상관없어요.

- `17 % 5` → 17 = 5 × 3 + **2** 이므로 `2` (몫 3이 아니에요)
- `10 % 2` → `0` (2로 나누어떨어지면 짝수)
- `7 % 2` → `1` (2로 나눈 나머지가 1이면 홀수)
- `50 % 10` → `0` (50의 10%인 5가 아니에요)

나머지는 "묶고 남는 개수"를 구할 때 써요. 사탕 23개를 4개씩 봉지에 담으면 `23 % 4`, 즉 3개가 남아요. 몫(봉지 수)이 필요하면 나머지를 뺀 뒤 나누면 돼요: `(23 - 23 % 4) / 4`는 `5`예요.

### 복합 대입: 대입을 줄여 쓰기

`score = score + 10`처럼 "자기 자신에 계산해서 다시 넣기"는 아주 흔해서 줄임말이 있어요.

| 줄임말 | 같은 뜻 |
|---|---|
| `x += 5` | `x = x + 5` |
| `x -= 5` | `x = x - 5` |
| `x *= 5` | `x = x * 5` |
| `x /= 5` | `x = x / 5` |
| `x %= 5` | `x = x % 5` |
| `x **= 2` | `x = x ** 2` |

연산 기호는 **`=` 앞**에 붙여요. 그리고 오른쪽은 **전체를 먼저 계산**해요. `x *= 2 + 3`은 `x = x * (2 + 3)`이에요. `x = x * 2 + 3`이 아니에요.

### 증가·감소: 1씩 바꾸기

1을 더하거나 빼는 일은 더 흔해서 더 짧은 줄임말이 있어요. `count++`(또는 `++count`)는 `count += 1`, `count--`(또는 `--count`)는 `count -= 1`과 같은 일을 해요.

한 줄에 따로 쓰면(`count++;`) 앞에 붙이든 뒤에 붙이든 같아요. 차이는 **다른 식 안에서 그 값을 쓸 때**만 생겨요.

| 식 | `count`는 | 식의 값은 |
|---|---|---|
| `count++` (뒤에 붙임) | 1 늘어나요 | 늘리기 **전** 값 |
| `++count` (앞에 붙임) | 1 늘어나요 | 늘린 **뒤** 값 |

`++`는 변수의 값을 바꾸는 연산이라 `const`로 만든 상수에는 쓸 수 없어요(`TypeError`). 헷갈릴 때는 `count++;`를 따로 한 줄에 쓰고, 다음 줄에서 `count`를 쓰는 편이 읽기 쉬워요.
</Section>

<Pitfall misconception="js.mc.division-truncates">
<Wrong>`7 / 2`는 몫만 남아서 `3`이다.</Wrong>
<Actual>`7 / 2`는 `3.5`예요. JavaScript의 `/`는 소수까지 계산해요.</Actual>
<Right>나누어떨어지지 않으면 소수가 나온다고 생각해요. 남는 수가 필요하면 `%`로 나머지를 구해요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.caret-is-power">
<Wrong>2의 3제곱은 `2 ^ 3`이라고 쓴다.</Wrong>
<Actual>`2 ^ 3`은 오류 없이 `1`이 나와요. `^`는 거듭제곱이 아닌 다른 연산(비트 연산)이에요.</Actual>
<Right>거듭제곱은 `2 ** 3`처럼 별표 두 개로 써요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.expression-changes-variable">
<Wrong>`score + 10;`이나 `console.log(score + 10);`을 실행하면 `score`가 10 늘어난다.</Wrong>
<Actual>계산식은 새 값을 만들 뿐이라 `score`는 그대로예요. `score + 10;`만 쓴 줄은 계산하고 결과를 버려요.</Actual>
<Right>변수를 바꾸려면 대입해요: `score = score + 10;` 또는 `score += 10;`.</Right>
</Pitfall>

<Pitfall misconception="js.mc.always-left-to-right">
<Wrong>`2 + 3 * 4`는 왼쪽부터 계산해서 `20`이다.</Wrong>
<Actual>`*`가 `+`보다 먼저라서 `2 + 12`, 즉 `14`예요.</Actual>
<Right>`* / %`가 `+ -`보다 먼저예요. 더하기를 먼저 하고 싶으면 `(2 + 3) * 4`처럼 괄호를 써요. 평균을 구할 때 `(a + b + c) / 3`의 괄호를 빠뜨리는 실수가 대표적이에요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.multiply-before-divide">
<Wrong>곱셈이 나눗셈보다 먼저라서 `12 / 2 * 3`은 `12 / 6`, 즉 `2`다.</Wrong>
<Actual>`*`와 `/`는 같은 순서라 왼쪽부터 계산해요. `6 * 3`이라서 `18`이에요.</Actual>
<Right>같은 순서의 연산자는 왼쪽부터 계산해요. `12 / (2 * 3)`을 원하면 괄호를 써요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.remainder-is-percent">
<Wrong>`%`는 퍼센트라서 `50 % 10`은 "50의 10%"인 `5`다.</Wrong>
<Actual>`50 % 10`은 50을 10으로 나눈 나머지 `0`이에요.</Actual>
<Right>`%`는 나머지 연산자예요. 백분율은 `50 * 10 / 100`처럼 직접 계산해요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.remainder-is-quotient">
<Wrong>`17 % 5`는 몫인 `3`이다.</Wrong>
<Actual>`17 % 5`는 나머지 `2`예요(17 = 5 × 3 + 2).</Actual>
<Right>`%`는 나머지예요. 몫이 필요하면 `(17 - 17 % 5) / 5`처럼 나머지를 뺀 뒤 나눠요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.compound-operator-reversed">
<Wrong>`total =+ 500;`이라고 써도 `total += 500;`과 같다.</Wrong>
<Actual>`total =+ 500`은 `total = +500`으로 읽혀서 `total`에 500이 **들어갈** 뿐 더해지지 않아요. 오류가 나지 않아서 결과만 이상해져요.</Actual>
<Right>연산 기호를 `=` 앞에 붙여 `+=`, `-=`로 써요. "더해서(+) 넣는다(=)" 순서로 기억해요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.compound-right-side-split">
<Wrong>`x *= 2 + 3`은 `x = x * 2 + 3`이다.</Wrong>
<Actual>`x *= 2 + 3`은 `x = x * (2 + 3)`이에요. `x`가 4라면 20이 돼요(11이 아니에요).</Actual>
<Right>복합 대입은 오른쪽 전체를 먼저 계산한 뒤 연산해서 넣어요.</Right>
</Pitfall>

<Pitfall misconception="js.mc.postfix-prefix-same">
<Wrong>`let b = a++;`와 `let b = ++a;`는 같은 값을 `b`에 넣는다.</Wrong>
<Actual>`a`가 5일 때 `a++`의 값은 늘리기 전의 5, `++a`의 값은 늘린 뒤의 6이에요. 둘 다 `a`는 6이 돼요.</Actual>
<Right>뒤에 붙이면 "쓰고 나서 늘리기", 앞에 붙이면 "늘리고 나서 쓰기"예요. 헷갈리면 `a++;`를 따로 한 줄에 써요.</Right>
</Pitfall>

<Section kind="in-practice">
쇼핑몰의 결제 화면은 산술 연산의 모음이에요.

```js
const price = 12000;     // 상품 가격
const count = 3;         // 수량
const discountRate = 10; // 할인율(%)
const shippingFee = 3000;

let total = price * count;              // 36000
total -= total * discountRate / 100;    // 10% 할인 → 32400
total += shippingFee;                   // 35400
console.log("결제 금액:", total);
```

- 할인율 10%는 `total * 10 / 100`으로 계산해요. `%` 연산자로는 백분율을 구할 수 없어요.
- 할인은 상품 금액에만, 배송비는 할인 뒤에 더해요. 계산 **순서**가 요구사항이에요.

시간 표시에도 `%`가 자주 쓰여요. 동영상 길이가 135초라면 분은 `(135 - 135 % 60) / 60`, 즉 2, 초는 `135 % 60`, 즉 15라서 "2:15"로 보여 줄 수 있어요. 게임의 점수와 남은 목숨은 `score += 100`, `lives--`처럼 복합 대입과 감소 연산자로 바꿔요.
</Section>

<Section kind="summary">
- `+ - * / **`로 계산해요. `/`는 소수까지 계산하고, 거듭제곱은 `^`가 아니라 `**`예요.
- 계산식은 새 값을 만들 뿐 변수를 바꾸지 않아요. 바꾸려면 대입해요.
- `* / %`가 `+ -`보다 먼저이고, 같은 순서끼리는 왼쪽부터 계산해요. 의도가 다르면 괄호를 써요.
- `%`는 나머지예요. 짝수·홀수, 묶고 남는 개수, 시간 변환에 써요. 퍼센트가 아니에요.
- `x += 5`는 `x = x + 5`예요. 오른쪽 전체를 먼저 계산하고, 기호는 `=` 앞에 붙여요.
- `x++`와 `++x`는 모두 1을 늘리지만, 식의 값은 늘리기 전과 늘린 뒤로 달라요.
</Section>
