<Section kind="summary">
풀기 전에, 또는 막혔을 때 이 요점을 다시 확인해 보세요.

- 함수를 선언하면 만들어 두기만 해요. 본문은 `이름(인수)`처럼 괄호를 붙여 호출할 때마다 처음부터 실행돼요. 괄호 없는 이름은 함수 자체예요.
- 인수는 이름이 아니라 순서대로 매개변수에 들어가요. 덜 넘긴 매개변수는 `undefined`이고, 남는 인수는 버려져요.
- `return 값;`은 값을 돌려주고 함수를 바로 끝내요. `return`이 없거나 실행된 갈래에 없으면 결과는 `undefined`예요(`null`이 아니에요). `console.log`는 보여 주기만 해요.
- 출력과 바깥 변수 바꾸기는 부수 효과예요. 호출할 때 한 번 일어나고, 반환값을 담은 변수를 다시 써도 함수는 다시 실행되지 않아요. 같은 인수에 늘 같은 값을 돌려주고 부수 효과가 없으면 순수 함수예요.
- 함수 표현식과 화살표 함수는 함수를 변수에 담아요. 화살표 함수의 중괄호 본문은 `return`을 직접 써야 해요. `const`로 만든 함수는 그 줄보다 위에서 부르면 `ReferenceError`이고, 함수 선언은 위에서 불러도 돼요.
- 기본값은 매개변수가 `undefined`일 때만 쓰여요. 나머지 매개변수 `...rest`는 맨 끝에 하나만 두고, 앞 매개변수가 받고 남은 인수를 묶음으로 모아요.
- 블록과 함수 안의 `let`·`const`는 그 안에서만 보여요. 안쪽에서 같은 이름을 만들면 바깥 변수를 가리고, 안쪽 변수나 매개변수를 바꿔도 바깥 변수는 그대로예요. 엄격 모드에서 선언하지 않은 이름에 대입하면 `ReferenceError`예요.
- 콜백은 넘길 때가 아니라 받은 함수가 부를 때 실행돼요. 넘길 때는 괄호를 붙이지 않아요.
</Section>
