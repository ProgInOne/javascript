이 단원을 마치면 이런 걸 할 수 있어요

  • let과 const로 이름을 만들고 값을 넣을 수 있어요.
  • =를 "같다"가 아니라 "오른쪽 값을 왼쪽 이름에 넣는다"로 읽을 수 있어요.
  • 값이 바뀌는 이름과 바뀌면 안 되는 이름을 구분해 let과 const를 고를 수 있어요.
먼저 알면 좋아요 console.log 출력 문장과 실행 순서 · 모두 준비됐어요

왜 이름이 필요할까요

온라인 서점에서 주문 금액을 계산한다고 해봅시다. 책 가격 12000이 코드 곳곳에 숫자로 흩어져 있다면, 가격이 바뀔 때마다 모든 곳을 찾아 고쳐야 해요. 게다가 12000 * 3만 봐서는 12000이 무슨 값인지 알 수 없죠.

변수는 값에 이름을 붙여 두는 방법이에요. 이름을 한 번 정해 두면 그 이름으로 값을 꺼내 쓰고, 필요하면 새 값을 넣을 수 있어요.

let으로 만들고 =로 넣어요

let 뒤에 이름을 쓰면 새 변수가 만들어져요(선언). =는 오른쪽을 먼저 계산해서 그 결과를 왼쪽 이름에 넣으라는 뜻이에요(대입).

그럼 다른 변수로 계산한 값은 어떨까요? 실행하기 전에 결과를 먼저 예측해 보세요.

흔한 실수 · =를 "같다"로 읽어요
잘못된 생각
count = count + 1은 성립할 수 없는 식이다.
실제 동작
오른쪽 count + 1을 먼저 계산하고, 그 결과를 count에 넣어요.
올바른 이해
=는 "넣는다"로 읽어요. 같은지 비교할 때는 ===를 써요(모듈 3).

바뀌지 않을 이름은 const로

const로 만든 이름에는 처음 넣은 값 말고 다른 값을 다시 넣을 수 없어요. 바뀌면 안 되는 값을 const로 선언해 두면, 실수로 덮어쓸 때 JavaScript가 바로 알려 줘요.

언제 무엇을 쓸까요기본은 const로 쓰고, 값을 다시 넣어야 할 때만 let으로 바꾸세요. 코드를 읽는 사람이 "이 값은 바뀌는구나"를 바로 알 수 있어요.
